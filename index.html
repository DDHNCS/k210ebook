图像识别技术

课程总目录 · 使用说明与模块导航

本课程以 Kendryte K210 边缘 AI 开发板为载体，从 GPIO 外设控制一路走到摄像头采集、KPU 推理、模型训练与部署，共 18 个模块 · 40 学时。全教材采用任务驱动 + 活页式组织：每个模块由若干独立成页的活页构成，可拆装、可重组、可更新。本页是教材总入口——先读活页使用说明，再从下方模块导航按顺序进入各模块。

说明M-00

这本教材怎么用？

约 5 分钟

本教材采用活页式、工作手册式组织方式：整个课程由 18 个模块组成，每个模块又由若干独立成页的活页构成，每个活页承载一个完整的学习单元（任务卡、知识链接、工作实施、活动评价等）。活页可以单独取下、重新组合或替换，既方便教师按学情增删内容，也方便学生边学边记录、对照实施。

活页编号规则

编号示例含义
M5-T1-K2模块 5 · 任务 1 · 知识活页 2（K = Knowledge，知识）
M7-T3-W1模块 7 · 任务 3 · 工作活页 1（W = Work，工作 / 实操）
M4-T2-A1模块 4 · 任务 2 · 活动活页 1（A = Activity，活动）
M12-E1 / M12-X1模块评价活页（E = Evaluate）/ 模块拓展活页（X = eXpand）

五类活页，各管什么

K · 知识活页讲清"是什么、为什么"：概念、原理、参数、器件特性与工作过程。
W · 工作活页讲清"怎么做"：按步骤动手实施，边做边勾选、记录现象与结果。
A · 活动活页课堂上练：案例分析、流程排序、随堂检测（答案可折叠查看）。
E · 评价活页学习评价量表：自评 / 互评 / 师评 + 课后反思。
X · 拓展活页选做任务与参考资料：进阶实验、延伸阅读、下个模块预告。
一句话记住：K 学知识、W 练技能、A 做活动、E 作评价、X 拓视野——五类活页合起来就是一个完整的学习闭环。

说明M-02

开始学习前，先了解这四件事

约 3 分钟
序号事项说明
1按顺序学习模块按能力递进排列，每个模块封面页都标注了前置模块。建议从模块一开始顺序推进；模块十之后进入"识别"阶段，需要前面的摄像头、LCD 基础。
2进度自动保存各模块中"我已完成本任务"等勾选框会保存在本机浏览器（localStorage），下次打开同一台电脑的同一浏览器仍保留；换设备或清缓存会重置。
3可打印、可导出 PDF每个模块页面右上角有"打印教材"按钮，可直接打印或"另存为 PDF"；教材同时提供与网页对应的 PDF 版本（同一目录下 moduleN.pdf），表格与代码块已做防断页处理。
4配套资料在哪原理图、环境搭建工具、固件与模型包等资料见各模块的拓展活页（X）；SDK、烧录工具等开源资源在活页中给出了下载地址。
实验安全提醒：插拔杜邦线、摄像头与 LCD 排线前先断电；烧录时不要拔掉 USB 线；K210 开发板供电以 USB 为主，避免热插拔扩展模块。

课程结构总览

18 个模块按能力递进分为三个阶段：先把开发板"用起来"，再让 K210"看懂画面"，最后自己"训模型、做部署"。

总览M-03

三个阶段与学时分配

阶段模块主要内容学时
一、基础外设与图像采集 模块一 ~ 模块九 课程概述与环境搭建 → GPIO / LED / RGB / 按键中断 / 定时器 → LCD 显示与触摸、Flash 读写 → 摄像头采集 18 学时
二、图像识别核心 模块十 ~ 模块十四 神经网络与 CNN 原理、KPU 加速器 → 人脸检测 → 物体检测 → 公开模型部署与调优 → 图像分类（五分类花） 10 学时
三、模型训练与部署 模块十五 ~ 模块十八 百度飞桨在线训练（C 路线）→ Python 环境移植与 IDE → MaixHub 在线训练与部署（物体分类 / 物体检测，自行采集与标注数据集） 12 学时
合计40 学时
能力主线：会用外设 → 能采集图像 → 能跑模型推理 → 会换模型调参 → 能自己训练并部署模型。走到第三阶段，你已经完成一次完整的"数据采集 → 标注 → 训练 → 转换 → 部署 → 实测"AI 工程闭环。
双技术路线：模块一 ~ 模块十五走 C 语言（VSCode + Kendryte SDK）路线，模块十六 ~ 模块十八切换到 Python（MaixPy IDE）路线，两条路线对照学习，理解"同一颗芯片的不同开发方式"。

模块八2 学时
