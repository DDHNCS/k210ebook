知识活页M1-T1-K1

图像识别的基本概念与原理

约 15 分钟

1. 图像是怎么组成的

图像是二维图像用有限数字数值像素的表示。肉眼看到的一幅图，在计算机里其实是由大量基本像素点组成的——每个像素点都携带色彩种类与亮度等级信息。像素点越密集，图像越清晰；像素值越丰富，色彩与层次越逼真。

由像素点构成的、可以用数字数值描述和存储的图像，称为数字图像（又称数码图像、数位图像）。数字图像是计算机能够处理、识别的前提。

记忆锚点：图像 = 像素点矩阵；像素 = 色彩 + 亮度信息；数字图像 = 图像的数字表示，是图像识别的输入对象。

2. 什么是图像识别

图像识别，是指利用计算机对图像进行处理、分析和理解，从而识别出图像中各种不同模式的目标和对象的技术。它解决的问题是：让机器"看懂"图像里有什么（轮廓、特征、颜色、物体），并作出判断。

图像识别通常包括轮廓识别、特征识别、色彩识别、物体识别等类型，其中轮廓识别是重中之重——因为物体的形状轮廓是识别其身份的最基础信息。

图像识别的基本过程

约 10 分钟

图像识别的基本流程

无论识别对象是车牌、人脸还是工业零件，图像识别都遵循同一个基本流程：

① 信息获取
图像采集（摄像头等）
→
② 图像预处理
得到特征数据
→
③ 训练过程
建立识别模型
→
④ 识别
输出识别结果
  • 信息获取（图像采集）：通过摄像头、扫描仪等设备把现实场景转化为数字图像，是识别过程的起点。
  • 图像预处理：对采集到的图像进行去噪、增强、分割等处理，提取出具有区分度的特征数据，为后续识别做准备。
  • 训练过程：用大量带标签的样本特征"教会"识别模型——这是机器学习和卷积神经网络发挥作用的核心环节。
  • 识别：把待识别图像的特征与训练好的模型比对，输出"是什么"的结论。
联系本课程：K210 芯片内置卷积神经网络硬件加速器（KPU），可以在芯片本地完成"训练好的模型"的推理识别，这就是"边缘计算"的含义——识别不出云端，直接在设备端完成。

图像识别的应用领域

约 15 分钟

图像识别的三个发展阶段

图像识别技术经历了由浅入深的三个发展阶段：对文字信息的识别 → 对数字化信息的识别 → 对物体的识别。随着阶段演进，图像识别不断与各行业技术结合，逐步拓展至交通、安防、医学、农业等众多领域。

主要应用与发展方向

领域典型应用技术要点
交通 智能交通系统（ITS）：道路识别、车辆检测、车牌检测 在道路识别、车辆车牌检测等方面展现巨大优势
安防 视频智能分析系统：人脸识别、人脸支付、智能自动化监控 基于图像识别技术的视频智能分析
医学 CT 成像、微创手术导航、心脏与脑结构等器官识别 CT 技术是图像识别技术的拓展应用；手术导航、器官识别地位不可替代
农业 病虫害诊断、农作物生长检测 在农业领域发挥巨大作用

除此之外，图像识别的主要应用与发展方向还包括字符识别（OCR）、机器视觉识别、图形图像识别、生物医学等。本课程后续将重点围绕智能识别车牌与人脸识别两大典型应用展开，K210 正是实现这类端侧识别的主流硬件平台。

K210 芯片概述

约 20 分钟

1. 芯片定位与出身

Kendryte K210 是一款集成了机器视觉与机器听觉能力的系统级芯片（SoC）。它采用台积电（TSMC）超低功耗 28nm 先进制程，搭载双核 64 位 CPU，拥有较好的功耗性能、稳定性与可靠性。该方案主打零门槛开发，可在最短时间内部署到产品中，为产品赋予人工智能功能。

K210 既是一款定位于 AI 和 IoT 领域的 SoC，也是一款使用非常方便的 MCU（微控制器）——开发门槛低，非常适合作教学与快速原型开发。

芯片类型
SoC（系统级芯片）+ MCU
制造工艺
TSMC 28nm 超低功耗制程
处理器
双核 64 位 RISC-V CPU（每核含 FPU）
工作温度
-40°C ～ 125°C，稳定可靠
应用定位
AI 与 IoT 领域，零门槛 AI 开发
名称由来
Kendryte（勘智）= 勘物探智

2. 名字里的含义：勘物探智

"Kendryte"中文含义为"勘智"，取自"勘物探智"：

  • 勘物——芯片主要应用于物联网（IoT）领域，探测感知万物；
  • 探智——芯片主要提供人工智能解决方案，在人工智能领域探索。

K210 的核心能力：机器视觉与机器听觉

约 20 分钟

1. 机器视觉（看的能力）

K210 是零门槛机器视觉嵌入式解决方案，可以在低功耗情况下进行卷积神经网络计算，实现：

视觉能力
  • 基于卷积神经网络的一般目标检测
  • 基于卷积神经网络的图像分类任务
  • 人脸检测和人脸识别
  • 实时获取被检测目标的种类
  • 实时获取被检测目标的大小与坐标

2. 机器听觉（听的能力）

芯片上自带高性能麦克风阵列音频处理器，可以进行实时声源定向与波束形成，实现：

听觉能力
  • 声源定向
  • 声场成像
  • 波束形成
  • 语音唤醒
  • 语音识别

3. 视觉 + 听觉的综合应用

K210 可结合机器视觉和机器听觉能力，提供更强大的功能：

  • 通过声源定位和声场成像辅助机器视觉对目标的跟踪；
  • 通过一般目标检测获得目标方位后，辅助机器听觉对该方位进行波束形成；
  • 根据摄像头传来的图像获得人的方向，使麦克风阵列通过波束形成指向该人；
  • 根据麦克风阵列确定说话人的方向，转动摄像头指向该人。
一句话记忆：视觉负责"看"（检测、分类、人脸），听觉负责"听"（定向、成像、识别），两者配合可实现"看声辨位、闻声转头"的智能交互。

K210 的系统架构

约 30 分钟

1. 功能框图

K210 包含RISC-V 64 位双核 CPU，每个核心内置独立 FPU（浮点运算单元）。核心功能是机器视觉与听觉：

CPU 单元RISC-V 64 位双核
每核独立 FPU
KPUCNN 卷积神经网络加速器
APU音频加速器（麦克风阵列）
FFT快速傅里叶变换加速器
AES / SHA256加密与哈希硬件加速
SRAM + DMA高性能低功耗存储
强大的数据吞吐
  • KPU：卷积人工神经网络（CNN）硬件加速器，可高性能进行卷积运算，是机器视觉的"引擎"。
  • APU：处理麦克风阵列输入的音频加速器，是机器听觉的"引擎"。
  • FFT：快速傅里叶变换加速器，可进行高性能复数 FFT 计算，因此对大多数机器学习算法，K210 都具备高性能处理能力。
  • AES / SHA256：内嵌硬件加速器，提供基本安全功能（数据加密与完整性校验）。
  • SRAM 与 DMA：高性能、低功耗的 SRAM，配合功能强大的 DMA，数据吞吐能力性能优异。

2. 丰富的外设单元

K210 具备丰富的外设单元，可满足海量应用场景：

DVP摄像头接口
GPIO通用输入输出
UART串口通信 ×3
SPI串行外设接口
I²C双线通信 ×3
I²S音频总线
Timer / PWM定时与脉宽调制
RTC实时时钟
WDT看门狗
JTAG / OTP / FPIOA调试 / 一次性编程 / 可编程 IO 阵列

3. 时钟树

K210 使用一路外部低频时钟，并使用三路 PLL提供高频时钟：

  • PLL0：为 CPU 与大部分外设提供时钟；
  • PLL1：为 AI 加速核提供时钟；
  • PLL2：为 I²S 音频提供时钟。

其中，AI 只能选择 PLL1 作为时钟源，I²S MCLK 只能选择 PLL2 作为时钟源；其余外设可以在外部时钟与 PLL0 之间选择（通过 PLL BYPASS 选择外部时钟）。PLL2 可以与 PLL0 级联，以获得更精准的音频采样频率。

与后面任务的联系：任务 4 的 main.c 中调用 sysctl_pll_set_freq(SYSCTL_PLL0, 800000000)，就是把 PLL0 配置为 800 MHz——你将在第一个程序里亲手设置时钟。

Hello World 程序解析

约 20 分钟

程序位于 SDK 的 src/hello_world/main.c，运行时会从 USB 串口打印数据。完整源码如下：

/* Copyright 2018 Canaan Inc.

#include <bsp.h>
#include <sysctl.h>

int core1_function(void *ctx)
{
    uint64_t core = current_coreid();
    printf("Core %ld Hello world\n", core);
    while(1);
}

int main(void)
{
    sysctl_pll_set_freq(SYSCTL_PLL0, 800000000);
    uint64_t core = current_coreid();
    int data;
    printf("Core %ld Hello world\n", core);
    register_core1(core1_function, NULL);

    /* Clear stdin buffer before scanf */
    sys_stdin_flush();

    scanf("%d", &data);
    printf("\nData is %d\n", data);
    while(1)
        continue;
    return 0;
}

逐段解读

代码作用
#include <bsp.h>
#include <sysctl.h>		引入板级支持包与系统控制（时钟）头文件，获得系统 API 与宏定义
core1_function(void *ctx)核心 1 上运行的函数：获取当前核心编号并打印 "Core 1 Hello world"，随后死循环
sysctl_pll_set_freq(SYSCTL_PLL0, 800000000)设置 PLL0 频率为 800 MHz（对应知识活页 K2-3 的时钟树，PLL0 为 CPU 提供时钟）
current_coreid()返回当前运行核心的编号（main 运行在核心 0）
printf("Core %ld Hello world\n", core)在核心 0 打印 Core 0 Hello world
register_core1(core1_function, NULL)把 core1_function 注册到核心 1，核心 1 随即开始执行并打印 "Core 1 Hello world"
sys_stdin_flush()清空标准输入缓冲区，保证 scanf 前缓冲区干净（注释 "Clear stdin buffer before scanf"）
scanf("%d", &data)等待用户在串口终端输入一个整数
printf("\nData is %d\n", data)回显用户输入的整数
while(1) continue;主循环空转，防止程序退出
重点理解——双核：K210 是双核芯片。程序启动后核心 0 执行 main，核心 1 执行 core1_function，所以串口会依次打印 Core 0 Hello world 和 Core 1 Hello world。这验证了芯片双核 CPU 与多核编程的基础机制。
