从人工智能到深度学习

约 15 分钟

1. 人工智能、机器学习与深度学习

人工智能（Artificial Intelligence，AI）是让机器能够像人一样思考、学习、决策的技术科学。机器学习（Machine Learning，ML）是实现人工智能的一种方法，它让计算机通过数据学习规律，而不是显式地编写规则。深度学习（Deep Learning，DL）是机器学习的一个分支，它利用多层神经网络自动提取数据特征，模仿人脑的工作方式。

AI 人工智能
目标：让机器像人一样
→
ML 机器学习
手段：从数据学规律
→
DL 深度学习
核心：多层神经网络

三者关系可以概括为：人工智能是目标，机器学习是实现人工智能的手段，深度学习是机器学习中最核心、最强大的实现方式。本课程学习的图像识别技术，正是深度学习在计算机视觉领域的重要应用。

2. 计算机视觉与图像识别

计算机视觉（Computer Vision，CV）是让计算机"看懂"图像和视频的科学。图像识别是计算机视觉的核心任务之一，其基本流程为：信息获取 → 图像预处理 → 特征提取 → 模型训练 → 识别输出。

典型任务说明
图像分类判断整幅图像属于哪个类别，如图中是猫还是狗
目标检测不仅判断类别，还要框出目标的位置
人脸检测与识别检测出是否有人脸，并识别人脸的身份
语义分割对图像中的每个像素进行分类
记忆锚点：AI ⊃ ML ⊃ DL；图像识别 = 让计算机"看懂"图，流程五步：获取 → 预处理 → 特征 → 训练 → 输出。
知识活页M10-T1-K2

人工神经网络与卷积神经网络

约 20 分钟

1. 神经元模型

人工神经网络（Artificial Neural Network，ANN）是模仿生物神经网络行为特征的数学模型。神经网络本质上由大量相互连接的"神经元"组成，其基本结构包括三个部分：权重（Weight）、偏置（Bias）和激活函数（Activation Function）。

输入信号
x1、x2、x3…
→
加权求和
Σ(xᵢ·wᵢ) + b
→
激活函数
判断是否"兴奋"
→
输出
传给下一层

一个神经元接收多个输入信号，每个输入乘以对应的权重后求和，再加上偏置，最后通过激活函数输出结果。神经元可以形象地理解为：把许多输入信号按不同的重要程度（权重）加权求和，再判断这个信号总和是否达到"兴奋"的阈值（偏置），若达到则激活并输出。神经网络的学习过程，就是不断调整权重和偏置，使网络的输出不断逼近期望结果的过程。

2. 层次结构

一个典型的人工神经网络由多层神经元构成：输入层（接收外部输入数据）、隐藏层（特征提取和变换，可以有多层）、输出层（输出分类或回归结果）。当隐藏层数量较多时，神经网络就演变为"深度神经网络"（DNN），深度学习由此得名。

3. 卷积神经网络（CNN）

卷积神经网络（Convolutional Neural Network，CNN）是一种基于卷积运算的深度学习模型，是当前图像识别领域最主流的神经网络架构。CNN 通过卷积、池化、激活等运算组合，能够自动从图像中提取从低级到高级的层次化特征：浅层卷积提取边缘、角点等低级特征，深层卷积组合出人脸、车辆等高级语义特征。

4. 卷积运算

卷积是信号处理和图像处理中非常常用的技术。在深度学习中，卷积层的过滤器（卷积核）并不进行反转，本质上是执行逐元素乘法和加法运算。设 C 为卷积核，Large 为输入图像，Small 为输出图像，经过卷积（矩阵乘法）后，大图像被下采样为小图像：C × Large = Small。卷积核在输入图像上滑动，对应位置的元素相乘后累加，得到输出图像的一个像素点。

K210 的 KPU 支持两种卷积内核：1×1 卷积和 3×3 卷积。其中深度可分卷积（Depthwise Separable Convolution）是一种高效的卷积方式，分两步完成：第一步，每个卷积核只与输入层的一个通道卷积（不使用所有通道），得到对应的特征图；第二步，应用 1×1 卷积扩展通道深度。深度可分卷积大幅减少了计算量，是许多轻量级 MobileNet 类模型在嵌入式平台高效运行的关键。

5. 池化、激活与全连接

运算作用与要点
池化不改变深度但缩小矩阵大小（高分辨率→低分辨率）；降低空间尺寸减少计算量、扩大感受野、防止过拟合；常见最大池化与平均池化
激活为网络引入非线性；非线性建模 + 构建稀疏矩阵；常用 ReLU、Sigmoid、Tanh；KPU 支持任意形式的激活函数
全连接把特征图展开（flatten）映射为最终输出；图像分类通常配合 Softmax 输出每个类别的概率

6. 目标检测与 YOLO

目标检测是图像识别的核心任务，K210 的 KPU 上主要运行 YOLO（You Only Look Once，只看一次）框架的目标检测算法。YOLO 的核心思想是把目标检测看作回归问题，直接在整幅图像上预测目标的位置（边界框）和类别，一次性输出所有检测结果。相比传统的滑窗法，YOLO 速度快得多，非常适合在 K210 这类嵌入式低功耗平台上实时运行。

记忆锚点：卷积提特征、池化降尺寸、激活加非线性、全连接出结果；YOLO"只看一次"出框 + 类别，适合嵌入式。
知识活页M10-T1-K3

KPU 加速器与工具链

约 20 分钟

1. KPU 的功能

KPU（Knowledge Processing Unit，知识处理单元）是 K210 芯片内部的一个神经网络处理器，它可以在低功耗的情况下实现卷积神经网络计算，实时获取被检测目标的大小、坐标和种类，对人脸或者物体进行检测和分类。简单来说，KPU 能加载和运行不同的神经网络模型，实现各种机器视觉功能。

KPU 相当于 K210 芯片中的"GPU"（显卡），本质是实现高速的图像数据运算。它内置卷积（Convolution）、批归一化（Batch Normalization，BN）、激活（Activation）、池化（Pooling）运算单元，可以对人脸或物体进行实时检测。

2. KPU 的特点

支持主流训练框架按照特定限制规则训练出来的定点化模型，对网络层数无直接限制
支持每层卷积神经网络参数单独配置，包括输入输出通道数目、输入输出行宽列高
支持两种卷积内核：1×1 和 3×3
支持任意形式的激活函数
实时工作时最大支持神经网络参数大小为 5.5MiB 到 5.9MiB
非实时工作时最大支持网络参数大小为 （Flash 容量 - 软件体积）

3. 模型编译器与 nncase

使用 KPU 时，必须结合模型编译器（Model Compiler）。K210 目前支持的深度学习模型类型有 TensorFlow、TensorFlow Lite（tflite）、Caffe1.0 以及 ONNX，并且需要借助专门工具来转换。

nncase（https://github.com/kendryte/nncase）是 K210 官方提供的模型转换工具，它用来将训练好的模型转换成 KPU 能够识别的 kmodel 格式文件。当 K210 运行 C 代码时，能够加载 6MB 左右的模型；当运行 MaixPy 时，能够加载 3MB 左右的模型。

格式说明
kmodelnncase 转换后的神经网络模型文件，是 KPU 运行所需的格式
kfpkg由 flash-list.json 文本文件（记录固件和模型烧录地址）、.bin 固件文件、其他二进制文件组成的打包文件，用于代码与模型分开烧录

4. 与 KPU 相关的函数（头文件 kpu.h）

API作用
kpu_single_task_init / deinit初始化 / 反初始化单任务 KPU
kpu_model_load_from_buffer从内存缓冲区加载 kmodel 模型
kpu_load_kmodel加载 kmodel 模型文件到 KPU 任务句柄
kpu_model_free释放模型占用的内存
kpu_run_kmodel将待处理图像数据送入 KPU 运行模型
kpu_get_output获取 KPU 推理输出的结果数据（如特征值、检测框坐标等）
kpu_start启动 KPU
记忆锚点：实际编程流程：加载 kmodel → 获取摄像头当前帧 → 调用 kpu_run_kmodel → 获取输出。模型先用 nncase 转换，再随程序加载。

2. 四种卷积核（conv_data_demo[4]）

每组卷积核是 RGB 三通道各一个 3×3 核（9 个数 × 3 通道），KPU 用它对每个像素做 3×3 邻域加权求和：

模式卷积核（单通道 3×3）效果
origin0 0 0 / 0 1 0 / 0 0 0单位核，输出 = 原像素，保持原始画面
edge-1 -1 -1 / -1 8 -1 / -1 -1 -1拉普拉斯算子，提取轮廓与边缘
sharp-1 -1 -1 / -1 9 -1 / -1 -1 -1锐化算子，增强细节对比度
relievo2 0 0 / 0 -1 0 / 0 0 -1浮雕算子，产生立体浮雕视觉效果

void rgb888_to_565(uint8_t *src_r, uint8_t *src_g, uint8_t *src_b, uint16_t *dst, uint32_t len)
{

            (((uint16_t)src_g[i + 1] >> 2) << 5) +
            (((uint16_t)src_b[i + 1]) >> 3);

    }
}

* @brief 主函数，程序的入口
*/
int main(void)
{
    hardware_init();
    io_set_power();
    /* 时钟：PLL0 800MHz / PLL1 300MHz / PLL2 45.1584MHz */
    sysctl_pll_set_freq(SYSCTL_PLL0, 800000000UL);
    sysctl_pll_set_freq(SYSCTL_PLL1, 300000000UL);
    sysctl_pll_set_freq(SYSCTL_PLL2, 45158400UL);
    uarths_init();
    plic_init();
    sysctl_enable_irq();

    printf("LCD init\r\n");
    lcd_init();
    lcd_draw_picture_half(0, 0, 320, 240, gImage_logo);
    sleep(1);

    printf("ov2640 init\r\n");
    ov2640_init();
    init_key();  /* 按键初始化 */

    /* KPU任务初始化：设置3×3卷积核 */
    kpu_task_t task;
    conv_init(&task, CONV_3_3, conv_data);
    printf("KPU TASK INIT, FREE MEM: %ld\r\n", get_free_heap_size());
    printf("Please press the keypad to switch mode\r\n");

    while (1)
    {
        while (g_dvp_finish_flag == 0)  /* 等摄像头一帧完成 */
            ;
        /* KPU 运算：输入 g_ai_buf_in，输出 g_ai_buf_out */
        conv_run(&task, g_ai_buf_in, g_ai_buf_out, kpu_done);
        while (!g_ai_done_flag)  /* 等KPU算完 */
            ;
        g_ai_done_flag = 0;
        g_dvp_finish_flag = 0;

        /* RGB888 → RGB565 */
        rgb888_to_565(g_ai_buf_out, g_ai_buf_out + 320 * 240, g_ai_buf_out + 320 * 240 * 2,
            (uint16_t *)g_display_buf, 320 * 240);
        draw_text();  /* 左上角写当前模式 */
        lcd_draw_picture(0, 0, 320, 240, g_display_buf);

        if (key_flag)  /* 使用按键选择的卷积核 */
        {
            if (key_state == 0)  /* 按下 */
            {
                msleep(20);  /* 延迟去抖 */
                key_flag = 0;
                demo_index = (demo_index + 1) % 4;
                memcpy((void *)conv_data, (void *)(conv_data_demo[demo_index]),
                    3 * 3 * 3 * 3 * sizeof(float));
                conv_init(&task, CONV_3_3, conv_data);  /* 重新设置卷积核 */
            }
            else
            {
                msleep(20);
                key_flag = 0;
            }
        }
    }
    return 0;
}

4. 主流程解读

硬件准备：映射按键 + LCD + 摄像头引脚；BANK6/7 设 1.8V；PLL 三路时钟；plic_init 使能中断。

KPU 初始化：conv_init(&task, CONV_3_3, conv_data)——创建 KPU 任务并装入 3×3 卷积核；串口打印剩余内存。
采集与运算：等 g_dvp_finish_flag（摄像头帧完成）→ conv_run 把 g_ai_buf_in 送入 KPU 卷积 → 等 g_ai_done_flag（KPU 完成中断）。
转换与显示：rgb888_to_565 转 RGB565 → draw_text 左上角写模式名 → lcd_draw_picture 显示。
按键切换：按下中间按键（去抖）→ demo_index+1 取模 4 → memcpy 换卷积核 → conv_init 重新装入 → 画面切换到下一种滤波。
教材与工程差异：教材流程把"KPU 运算/转换/显示/按键"编号为步骤 9~13；工程源码实现一致，其中四种模式名分别为 origin / edge / sharp / relievo。
知识活页M10-T2-K2

关键代码详解

约 20 分钟

1. conv_init 与 conv_run（l_conv.c）

函数作用
conv_init(task, conv_x_x, conv_data)把卷积核装入 KPU 任务：CONV_1_1（1×1）或 CONV_3_3（3×3），并设置输入输出尺寸、通道等参数
conv_run(task, img_src, img_dst, callback)启动 KPU 运算：把输入图像送入，结果写入输出缓冲，运算完成触发回调

2. 中断与标志

kpu_done 是 KPU 运算完成的中断回调，只做一件事：g_ai_done_flag = 1；主循环等待该标志后再继续——和模块九 DVP"帧完成置标志"是同一个套路。

→
KPU 完成

→
转换显示
RGB565 + 模式名 + LCD

3. RGB888 → RGB565

KPU 输出的 AI 数据是 RGB888（每像素 3 字节），而 LCD 只支持 RGB565（每像素 2 字节）。转换即截取高位：R 取高 5 位（>>3）、G 取高 6 位（>>2）、B 取高 5 位（>>3），再按 16 位拼装。这就是实验总结第 (2) 条说的"数据格式不一样，需要转换后才能正常显示"。

4. 按键切换与卷积核重装

按键中断置 key_flag；主循环里检测到按下后 msleep(20) 去抖，demo_index = (demo_index+1) % 4 轮换模式，memcpy 把 conv_data_demo[demo_index] 的 27 个 float 复制到 conv_data，再 conv_init 重新装入 KPU 任务——改卷积核 → 改图像效果。

实验总结：① KPU 可以处理图像，产生不一样的视觉效果；② KPU 与 LCD 的数据格式不一样（KPU 输出 RGB888，LCD 要求 RGB565），需要转换后才能正常显示；③ 卷积、池化、激活等神经网络核心运算，是 KPU 完成各类图像识别任务的基础。
