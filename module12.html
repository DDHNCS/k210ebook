知识活页M12-T1-K1

物体检测任务与方案流程

约 15 分钟

1. 什么是物体检测

物体检测是计算机视觉中的经典问题之一，其任务是用框去标出图像中物体的位置，并给出物体的类别。从传统的人工设计特征加浅层分类器的框架，到基于深度学习的端到端检测框架，物体检测一步步变得愈加成熟。具体训练过程这里省略掉，下面只介绍 K210 如何对训练好的模型进行部署并输出识别结果。

2. K210 实时物体检测方案步骤

① 训练模型：用深度学习框架（如 YOLO）在数据集上训练出检测模型。
② 模型转换成 kmodel：用 nncase 等模型编译器把训练好的模型转成 KPU 能识别的 kmodel 格式。
③ K210 加载模型：kpu_load_kmodel 把 kmodel 加载进 KPU 任务句柄。
④ K210 获取视频图像：摄像头采集画面送入 KPU 运行，输出识别结果。

知识活页M12-T1-K3

输入预处理与参数

约 15 分钟

1. 为什么要把图像补成 320×256？

物体检测模型的输入分辨率是 320×256，而摄像头画面是 320×240——高度少了 16 行。工程的处理方法是：

填灰：memset(g_ai_od_buf, 127, 320*256*3) 把整个 AI 输入缓冲填充为 127（灰色，RGB 中间值）。
搬图：for cc 0~2（RGB 三通道）执行 memcpy(g_ai_od_buf + 320*(cc*256+8), g_ai_buf_in + cc*320*240, 320*240)——把每通道 320×240 画面居中放到 320×256 缓冲的中间（上下各留 8 行灰边）。
送模型：把 g_ai_od_buf（320×256×3）作为 kpu_run_kmodel 的源数据送入 KPU。
关键：模型输入尺寸必须与训练时一致，否则识别错误。这是"部署时最常见的坑"——分辨率、通道数、数据格式任何一个不对，输出都不可信。

2. 区域层参数：threshold 0.5 / nms 0.2

参数工程取值与人脸检测对比
threshold0.50.7 → 0.5：物体检测类别多、置信度分布不同，阈值调低减少漏检
nms_value0.20.3 → 0.2：去重更严格，同一物体只保留一个框
region_layer_init(&rl, 10, 8, 125, 320, 240)—网络输出 10×8×125（20 类 × 5 锚框 + 坐标等），比人脸检测 20×15×30 更扁

3. lable_init：类别名称预渲染

lable_init() 在程序启动时用 lcd_ram_draw_string 把 20 个类名预渲染成位图（黑底 + 类色文字，16 像素高）存进内存。检测到物体后，直接把对应类名的位图贴到框的左上角——比每帧现场画字符快得多。

记忆锚点：320×240 → 320×256（灰边填充居中）；threshold 0.5 管信不信、nms 0.2 管去重；类名提前画成位图、显示时直接贴图。

#define INCBIN_STYLE INCBIN_STYLE_SNAKE
#define INCBIN_PREFIX
#include "incbin.h"

#define PLL0_OUTPUT_FREQ 800000000UL
#define PLL1_OUTPUT_FREQ 400000000UL

volatile uint32_t g_ai_done_flag;
kpu_model_context_t obj_detect_task;
static region_layer_t obj_detect_rl;
static obj_info_t obj_detect_info;
#define ANCHOR_NUM 5
// 20 类物体检测锚框（比人脸检测的更大）
static float anchor[ANCHOR_NUM * 2] = {1.3221, 1.73145, 3.19275, 4.00944,
    5.05587, 8.09892, 9.47112, 4.84053, 11.2364, 10.0071};

#define LOAD_KMODEL_FROM_FLASH 0
#define CLASS_NUMBER 20
#if LOAD_KMODEL_FROM_FLASH
#define KMODEL_SIZE (1501 * 1024)
uint8_t *model_data;
#else
INCBIN(model, "detect.kmodel");  // 模型编进固件

/* KPU 完成回调：置标志 */
static int ai_done(void *ctx)
{
    g_ai_done_flag = 1;
    return 0;
}

/* 20 类标签：名称 + 框颜色 */

typedef struct {
    char *str; uint16_t color;
    uint16_t height; uint16_t width; uint32_t *ptr;

class_lable_t class_lable[CLASS_NUMBER] =
{
    { "aeroplane", NAVY }, { "bicycle", DARKGREEN },

    { "car", DARKGREY }, { "cat", BLUE },

/* 类别名称预渲染成位图（黑底 + 类色文字） */
static void lable_init(void)
{
#if (CLASS_NUMBER > 1)
    uint8_t index;
    // 逐个把类名画进 lable_string_draw_ram 缓冲
    class_lable[0].height = 16;
    class_lable[0].width = 8 * strlen(class_lable[0].str);
    class_lable[0].ptr = lable_string_draw_ram;
    lcd_ram_draw_string(class_lable[0].str, class_lable[0].ptr, BLACK, class_lable[0].color);

/* 画框回调：区域层每输出一个框就调用一次 */
static void drawboxes(uint32_t x1, uint32_t y1, uint32_t x2, uint32_t y2, uint32_t class, float prob)
{
    // 边界钳位到 319 / 239
    lcd_draw_rectangle(x1, y1, x2, y2, 2, class_lable[class].color);
    // 框左上角贴类别名称位图
    lcd_draw_picture(x1 + 1, y1 + 1, class_lable[class].width, class_lable[class].height, class_lable[class].ptr);
}

int main(void)
{
    sysclock_init();   /* 系统时钟初始化 */
    uarths_init();     /* 串口初始化 */
    hardware_init();   /* 硬件引脚初始化 */
    io_set_power();    /* 设置 IO 口电压 */
    plic_init();       /* 系统中断初始化 */
    lable_init();      /* 层初始化：预渲染 20 个类名位图 */

    printf("flash init\n");
    w25qxx_init(3, 0);
    w25qxx_enable_quad_mode();
#if LOAD_KMODEL_FROM_FLASH
    model_data = (uint8_t*)malloc(KMODEL_SIZE + 255);
    uint8_t *model_data_align = (uint8_t*)(((uintptr_t)model_data + 255) & (~255));
    w25qxx_read_data(0xA00000, model_data_align, KMODEL_SIZE, W25QXX_QUAD_FAST);
#else
    uint8_t *model_data_align = model_data;
#endif

    lcd_init();
    lcd_draw_picture_half(0, 0, 320, 240, logo);
    lcd_draw_string(100, 40, "Hello HNSW!", RED);
    lcd_draw_string(100, 60, "object detection demo!", BLUE);
    sleep(1);
    ov2640_init();

    /* 初始化物体检测模型 */
    if (kpu_load_kmodel(&obj_detect_task, model_data_align) != 0)
    {
        printf("\nmodel init error\n");
        while (1);
    }
    obj_detect_rl.anchor_number = ANCHOR_NUM;
    obj_detect_rl.anchor = anchor;
    obj_detect_rl.threshold = 0.5;
    obj_detect_rl.nms_value = 0.2;
    region_layer_init(&obj_detect_rl, 10, 8, 125, 320, 240);
    sysctl_enable_irq();
    printf("System start\n");

    while (1)
    {
        g_dvp_finish_flag = 0;
        while (!g_dvp_finish_flag);  // 等待采集中断

        /* 图像预处理：320×240 → 320×256（灰边填充居中） */
        memset(g_ai_od_buf, 127, 320*256*3);
        for (uint32_t cc = 0; cc < 3; cc++)
        {
            memcpy(g_ai_od_buf + 320 * (cc * 256 + (256 - 240) / 2),
                g_ai_buf_in + cc * 320 * 240, 320 * 240);
        }

        g_ai_done_flag = 0;
        kpu_run_kmodel(&obj_detect_task, g_ai_od_buf, DMAC_CHANNEL5, ai_done, NULL);
        while(!g_ai_done_flag);

        float *output; size_t output_size;
        kpu_get_output(&obj_detect_task, 0, (uint8_t **)&output, &output_size);
        obj_detect_rl.input = output;
        region_layer_run(&obj_detect_rl, &obj_detect_info);

        /* 显示视频图像 */
        lcd_draw_picture(0, 0, 320, 240, (uint32_t *)display_buf_addr);
        /* 画识别结果：每个框调一次 drawboxes */
        region_layer_draw_boxes(&obj_detect_rl, drawboxes);
    }
    return 0;
}

3. 主流程解读

初始化：时钟（PLL0 800MHz / PLL1 400MHz）→ 串口 → 引脚 → IO 1.8V → 中断；lable_init 预渲染 20 个类名位图。
Flash 与模型：w25qxx_init + 四倍模式；INCBIN 把 detect.kmodel（约 1.5MB）编进固件；kpu_load_kmodel 加载。
外部硬件：lcd_init + logo 与欢迎语 1 秒 → ov2640_init。
区域层：threshold 0.5、nms 0.2、网络 10×8×125（20 类）。

2. drawboxes 回调：每个检测框画"框 + 名称"

region_layer_draw_boxes(&rl, drawboxes) 遍历区域层输出的每个检测框，逐个调用回调：drawboxes(x1, y1, x2, y2, class, prob)。回调内部：

边界钳位：把 x2/y2 限制到 319/239，防止画出屏幕。
画彩色框：lcd_draw_rectangle(x1, y1, x2, y2, 2, class_lable[class].color)——2 像素宽的类色矩形。
贴名称：lcd_draw_picture(x1+1, y1+1, width, height, class_lable[class].ptr)——把预渲染的类名位图贴在框左上角。

3. 320×256 填充详解

模型输入 320×256，摄像头 320×240。三通道（RGB）分别处理：先 memset(g_ai_od_buf, 127, 320*256*3) 全填灰（127 = 中灰，避免补边产生强边缘干扰检测），再把每通道 320×240 画面 memcpy 到第 cc 通道的中间位置（偏移 320*(cc*256 + 8)，上下各留 8 行）。

4. 为什么物体检测能"一次框多个"？

YOLO 把整幅图分成网格，每个格子 + 5 组锚框可输出多个候选框；区域层用 threshold 0.5 过滤低置信度、NMS 0.2 合并重叠框后，obj_detect_info.obj_number 就是要画的框数——可以同时是 0 个、1 个或多个，这就是"多目标实时检测"。

实验总结：① 物体检测与人脸检测大部分是相同的；② 物体检测可以检测多种物体。
