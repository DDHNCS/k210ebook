知识活页M17-T1-K2

数据集准备

约 15 分钟

1. 什么是数据集

数据集就是让 K210"记住"目标物体的照片集合，就像多看几眼一个人就会记住他一样，K210 需要从各个方位各个角度去观察需要识别的物体，来达到记忆的效果。也就是把物体的照片按照指定尺寸整理成数据集合。

2. 原始图像的要求

多方位：图像要尽可能多方位地反映目标的特点，每个目标的照片越多，训练出来的模型识别率就越高，但训练的时间也相对更长（一个目标的图片建议不少于 50 张）。
合规：图像的命名和分辨率要符合训练平台的要求。
获取：可以使用摄像头进行原始图像的获取，也可以使用摄像头拍摄一段目标视频，再转换成图片。
猫狗数据集范例：文件夹按类别命名（cat / dog），每类 ≥50 张、多角度多光照；训练时平台按标签名称（文件夹名）分类。
知识活页M17-T1-K3

物体分类模型的训练

约 15 分钟

在 MaixHub 平台训练物体分类模型的步骤（5 步）

1 注册登录：注册并登录 MaixHub 平台账号。
2 新建数据集：选择数据集类型为"分类"。数据集分为训练集（用于训练的图像）和验证集（用于检测识别效果的图像），验证集可以指定，也可以自动分配。
3 上传图片：上传准备好的分类数据集（如猫狗分类数据集 cat、dog），需要注意图片的标签，训练时按照标签名称分类。
4 创建训练任务：训练完成后创建任务，设置训练参数，包括图像缩放比例、部署平台等，即可开始训练。
5 下载模型：选择手动部署，下载模型文件。下载到的文件是基于 MaixPy 环境的，将下载的文件放入 TF 卡或 Flash 就可以运行了（前提是 K210 开发板已刷 Python 固件支持 MaixPy）。
记忆锚点：训练 5 步 = 注册 → 建数据集（训练/验证） → 上传（按标签分类） → 建任务（缩放+平台） → 下载（手动部署）。

知识活页M17-T2-K1

数据收集方法

约 20 分钟

收集目标：从各个方位各个角度"记住"目标

数据集就是让 K210"记住"目标物体的照片集合。收集时要注意多样性：同一物体不同姿态、距离、角度、光照、背景的照片越多，模型识别率越高（每类建议 不少于 50 张）。

摄像头拍摄：用开发板摄像头或手机/相机拍摄目标，变换角度、距离、光照，一张张拍够数量。
视频转图片：拍摄一段目标视频（缓慢转动/移动目标），再用工具按帧截取成图片——一次视频可快速得到几十张。
网络公开数据集：从公开数据集网站合规下载已有图片（注意授权与版权），可补充数量与场景多样性。
组合收集：拍摄 + 视频截图 + 公开数据混合，覆盖多场景，避免模型只"认识"实验室环境。
记忆锚点：收集三要点 = 多方位（角度/距离/光照）× 足数量（每类 ≥50 张）× 合规来源。

标注与数据集整理

约 15 分钟

1. 分类任务标注 = 文件夹即标签

分类数据集的标注很简单：每类物体建一个文件夹，文件夹名就是类别标签（如 cat、dog），把该类的照片放进对应文件夹。训练时平台按标签名称（文件夹名）分类。

2. 整理四步

清洗：剔除模糊、重复、错入类别、目标过小的照片。
命名：按平台要求命名（如序号 .jpg），命名与分辨率合规。
统一尺寸：训练平台会按缩放比例处理，但原始图尽量清晰、主体突出。
划分：数据集分为训练集（用于训练）和验证集（用于检测识别效果），可指定或自动分配。
记忆锚点：标注整理 = 建文件夹（标签）+ 清洗 + 命名合规 + 划分训练/验证集。

部署流程与核心代码

约 20 分钟

1. Python 环境下物体分类模型的部署

模型文件训练完成后，需要进行部署才能实现在 K210 上运行。以 MaixHub 训练的分类模型为例，部署步骤如下：

1 准备模型文件：把下载的模型包解压，得到 kmodel（模型）、main.py（程序）、report.json（训练报告）。
2 存放模型：将 kmodel 放入 TF 卡或 Flash（模型文件存放位置决定程序读取方式）。
3 打开程序：用 MaixPy IDE 打开 main.py（或教材简化版程序），核对 labels 与自建数据集一致。
4 调试运行：连接开发板并运行，验证分类效果。Flash 和 SD 卡两种存储方式的部署差异主要体现在模型文件的存放位置和主程序的读取方式上。

2. K210 实施物体分类的 Python 核心流程

from maix import camera, display, nn
# 加载物体分类模型（注：分类模型使用 Classifier）
classifier = nn.Classifier(model="/flash/model_kmodel")
while True:
    img = camera.capture()          # 采集摄像头图像
    img = img.resize(224, 224)  # 缩放为模型输入尺寸
    result = classifier.classify(img) # 进行分类
    label, score = result          # 获取类别和置信度
    print("class:", label, "score:", score)
    img.draw_string(10, 10, str(label), (255, 0, 0))
    display.show(img)
# 注：实际 API 以 MaixPy/Camera 板卡型号为准
记忆锚点：分类 = nn.Classifier + resize(224,224) + classify；label/score = 类别/置信度。
