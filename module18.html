知识活页M18-T1-K2

检测数据集与标注规范

约 15 分钟

1. 数据收集要求

多目标多场景：每类目标 ≥50 张，覆盖不同大小、位置、角度、光照；目标可多个同时出现（多目标检测场景）。
清晰完整：目标主体清晰、尽量完整出现在画面中，避免严重遮挡与模糊。
来源合规：摄像头拍摄、视频转图或公开数据集，注意授权。

2. 标注规范（检测训练的核心）

数据标注的规范性和一致性是目标检测训练的核心，标注框选的位置、大小、标签一致性都会直接影响训练效果。
框选位置：方框紧贴目标，尽量包住目标主体，不要留太大空白或切掉部分目标。
框选大小：每个目标一个框；大小统一规范，小目标与大目标框法一致。
标签一致性：同类目标用同一标签名（英文小写），不要混用（如 cat 与 Cat 视为两类）。
无遗漏：图中出现的每个目标都要标注，避免"有时标有时不标"。
记忆锚点：标注四规范 = 紧贴框 + 大小一致 + 标签一致 + 无遗漏。

kfpkg：目标检测模型部署与分类模型部署流程类似，都需要 "kfpkg 打包 → 模型烧录 → 程序适配 → 调试运行"。kfpkg 文件指定了模型的烧录地址，可直接烧进 Flash；也可以直接把 kmodel 放 TF 卡或烧到指定地址，但要保证程序中设定的模型地址与实际一致。

2. 目标检测模型的 Python 核心代码

from maix import camera, display, nn
# 加载目标检测模型（YOLO 系列，指定模型地址）
detector = nn.YOLO2(0x300000, 0.5, 0.3) # 模型地址、阈值、NMS
def on_detect(frame, detections):
    for d in detections:
        frame.draw_rect(d.x, d.y, d.w, d.h, (0, 255, 0)) # 框出目标
        frame.draw_string(d.x + 3, d.y + 3, d.class_name, (0, 255, 0))
while True:
    img = camera.capture()              # 采集图像
    detections = detector.detect(img)    # 运行检测
    on_detect(img, detections)        # 绘制检测结果
    display.show(img)                  # 显示画面
记忆锚点：检测 = nn.YOLO2(地址, 阈值, NMS) + detect() 返回检测框列表 + on_detect 画框标注；与模块十七分类（nn.Classifier + classify）对照。

自训检测模型部署实操

约 20 分钟

任务：把自训检测模型部署到 K210

1 下载解压。MaixHub 手动部署下载自训检测模型包，解压得到 kmodel、main.py、report.json。
2 检查报告。打开 report.json 确认 labels 与自建标注一致、anchors 已给出、输入输出尺寸正确。

注意：① main.py 按 MaixHub 生成版本（如 maixpy3 v0.4.8 或 v0.6.x）使用，若运行报错改用教材新版 nn.YOLO2 写法。② anchors 必须与模型匹配（来自 report.json），改错会导致检测失效。③ 模型默认读 /sd/m.kmodel（TF 卡），放 Flash 要改地址一致。④ 检测效果不理想时，先查标注质量（框准不准、有无漏标），再调阈值/NMS——标注决定上限。
