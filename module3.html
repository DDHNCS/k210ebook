约 15 分钟

R 灯

2. 元件特性

RGB 灯可以点亮红色、绿色、蓝色等颜色，再根据红、绿、蓝的不同亮度组合成其他颜色，例如黄色、紫色等。点亮规则与模块二一致：低电平点亮，高电平熄灭。

3. 硬件连接

K210 开发板出厂默认已经焊接好 RGB 灯。连接关系为：RGB 灯的 R 连接 IO6，G 连接 IO7，B 连接 IO8。

通道颜色硬件引脚（IO）驱动电路点亮条件
R红IO6（G11/R）串联限流电阻 R39（4.7KΩ）低电平
G绿IO7（G12/G）串联限流电阻 R40（1KΩ）低电平
B蓝IO8（F11/B）串联限流电阻 R41（1KΩ）低电平

电路上，RGB 灯（3535 规格）内部三颗 LED 的阳极共同接 +3.3V，阴极分别通过限流电阻（红色支路 4.7KΩ、绿色与蓝色支路各 1KΩ）接到 K210 的 IO6 / IO7 / IO8。引脚输出低电平时对应 LED 导通发光。

易错提醒：红色支路的限流电阻是 4.7KΩ（R39），绿色与蓝色支路是 1KΩ（R40/R41），三者阻值不同但功能相同——都是为了限流保护。
知识活页M3-T1-K2

RGB 灯发光原理

约 10 分钟

1. 结构与发光原理

RGB 灯内部由三颗颜色分别为红色、绿色和蓝色的 LED 组成，所以发光原理与 LED 完全一样（P-N 结中电子与空穴复合发光，光的颜色由材料决定，详见模块二 K2）。

2. 为什么能显示不同颜色

不同的是，三颗 LED 灯靠得很近，这样通过点亮不同的 LED、并改变各自的亮度，就可以设置不同的颜色，达到展示多种颜色的功能。

红 LED
IO6 低电平点亮
绿 LED
IO7 低电平点亮
蓝 LED
IO8 低电平点亮
→
RGB 三色合成
红/绿/蓝 + 不同亮度 → 多种颜色
记忆锚点：红 + 绿 → 黄，红 + 蓝 → 紫……三颗 LED 靠得越近、亮度组合越丰富，能显示的颜色就越多。这与后续屏幕显示、图像处理中的"三原色"是同一个原理。
知识活页M3-T1-K3

高速 GPIOHS 与 API

约 20 分钟

1. 什么是高速 GPIOHS

K210 除了模块二使用的通用 GPIO（gpio.h）外，还有一组高速 GPIOHS（High Speed GPIO），对应头文件 gpiohs.h。高速 GPIOHS 总共有 32 个，可配置输入输出模式，可配置上拉、下拉或高阻，每个 IO 都有单独的中断源，中断支持边沿和电平触发，每个 IO 都可以自由分配到 FPIOA 上的 48 个引脚之一。

2. 与通用 GPIO 的对比

对比项通用 GPIO（模块二）高速 GPIOHS（本模块）
数量8 个32 个
中断源8 个共用同一个总中断源每个 IO 都有单独的中断源
中断触发方式边沿触发、电平触发边沿触发、电平触发
IO 方向配置输入 / 输出输入 / 输出，可配置上拉、下拉或高阻
对应头文件gpio.hgpiohs.h
FPIOA 分配每个 IO 可分配到 48 个引脚之一每个 IO 可分配到 48 个引脚之一

3. 为用户提供的接口

API作用
gpiohs_set_drive_mode设置输入输出模式
gpiohs_set_pin设置引脚电平
gpiohs_get_pin读取引脚电平
gpiohs_set_pin_edge设置中断触发电平
gpiohs_set_irq设置中断（0.6.0 后不再支持，请使用 gpiohs_irq_register）
gpiohs_irq_register注册引脚中断服务
gpiohs_irq_unregister注销引脚中断
本实验只用输出类接口：先 gpiohs_set_drive_mode() 设为输出，再 gpiohs_set_pin() 控制电平。gpiohs_irq_register() 等中断接口留待后续按键中断实验使用。

pin_config.h 配置解析

约 15 分钟

1. 文件作用

与模块二一样，把硬件 IO 和软件 GPIO 功能抽出来单独设置，整个文件是三组宏定义。唯一的变化是：功能宏使用 FUNC_GPIOHS0（高速 GPIOHS 从 0 号开始），而不是模块二的 FUNC_GPIO0（通用 GPIO）。

HARDWARE-PIN
IO6 / IO7 / IO8，与原理图对应
→
SOFTWARE-GPIO
GPIOHS 0 / 1 / 2，与程序对应
→
FUNC-GPIO
FUNC_GPIOHS0 + 编号，绑定硬件 IO

2. 完整源码

/**
* @file         pin_config.c
* @brief        硬件引脚与软件GPIO的宏定义
*/
#ifndef _PIN_CONFIG_H_
#define _PIN_CONFIG_H_
/*****************************HEAR-FILE************************************/
#include "fpioa.h"

/*****************************HARDWARE-PIN*********************************/
// 硬件IO口，与原理图对应
#define PIN_RGB_R             (6)
#define PIN_RGB_G             (7)
#define PIN_RGB_B             (8)

/*****************************SOFTWARE-GPIO********************************/
// 软件GPIO口，与程序对应
#define RGB_R_GPIONUM          (0)
#define RGB_G_GPIONUM          (1)
#define RGB_B_GPIONUM          (2)

/*****************************FUNC-GPIO************************************/
// GPIO口的功能，绑定到硬件IO口
#define FUNC_RGB_R             (FUNC_GPIOHS0 + RGB_R_GPIONUM)
#define FUNC_RGB_G             (FUNC_GPIOHS0 + RGB_G_GPIONUM)
#define FUNC_RGB_B             (FUNC_GPIOHS0 + RGB_B_GPIONUM)

#endif /* _PIN_CONFIG_H_ */

3. 宏含义对照

宏值含义
PIN_RGB_R / G / B6 / 7 / 8RGB 灯三路硬件引脚号（对应原理图 IO6/IO7/IO8）
RGB_R_GPIONUM0红色通道的软件 GPIOHS 编号（程序操作对象）
RGB_G_GPIONUM1绿色通道的软件 GPIOHS 编号（程序操作对象）
RGB_B_GPIONUM2蓝色通道的软件 GPIOHS 编号（程序操作对象）
FUNC_RGB_R / G / BFUNC_GPIOHS0+0/1/2三路 GPIOHS 功能（分别绑定 IO6/IO7/IO8）
与模块二对照：模块二 LED 用 FUNC_GPIO0 + 编号（通用 GPIO），本模块 RGB 用 FUNC_GPIOHS0 + 编号（高速 GPIOHS）——映射用的功能宏必须与驱动 API 匹配（gpio_* 配 FUNC_GPIO0，gpiohs_* 配 FUNC_GPIOHS0）。

main.c 主程序解析

约 20 分钟

1. 完整源码

#include "sleep.h"
#include "gpiohs.h"
#include "pin_config.h"

/**
* @brief 硬件初始化，绑定GPIO口
*/
void hardware_init(void)
{
    // fpioa映射
    fpioa_set_function(PIN_RGB_R, FUNC_RGB_R);
    fpioa_set_function(PIN_RGB_G, FUNC_RGB_G);
    fpioa_set_function(PIN_RGB_B, FUNC_RGB_B);
}

/**
* @brief RGB灯灭
*/
void rgb_all_off(void)
{
    gpiohs_set_pin(RGB_R_GPIONUM, GPIO_PV_HIGH);
    gpiohs_set_pin(RGB_G_GPIONUM, GPIO_PV_HIGH);
    gpiohs_set_pin(RGB_B_GPIONUM, GPIO_PV_HIGH);
}

/**
* @brief 初始化RGB灯
*/
void init_rgb(void)
{
    // 设置RGB灯的GPIO模式为输出
    gpiohs_set_drive_mode(RGB_R_GPIONUM, GPIO_DM_OUTPUT);
    gpiohs_set_drive_mode(RGB_G_GPIONUM, GPIO_DM_OUTPUT);
    gpiohs_set_drive_mode(RGB_B_GPIONUM, GPIO_DM_OUTPUT);

    // 关闭RGB灯
    rgb_all_off();
}

/**
* @brief 主函数，程序的入口
*/
int main(void)
{
    // RGB灯状态，0=红灯亮，1=绿灯亮，2=蓝灯亮
    int state = 0;

    // 硬件引脚初始化
    hardware_init();
    // 初始化RGB灯
    init_rgb();

    while (1)
    {
        rgb_all_off();   // 先关闭RGB灯
        // 根据state的值点亮不同颜色的灯
        gpiohs_set_pin(state, GPIO_PV_LOW);
        msleep(500);
        state++;
        state = state % 3;
    }
    return 0;
}

2. 逐段解读

代码段作用
#include "sleep.h"提供 msleep() 毫秒延时函数（模块二用 sleep() 秒级延时）
#include "gpiohs.h"高速 GPIOHS 驱动头文件（模块二为 gpio.h）
hardware_init()FPIOA 映射：把 IO6/IO7/IO8 绑定为 GPIOHS 功能
init_rgb()设置三路 GPIOHS 为输出模式，并先关闭 RGB 灯
rgb_all_off()三路都输出高电平：LED 高电平熄灭
state = 0状态变量：0=红灯亮，1=绿灯亮，2=蓝灯亮
gpiohs_set_pin(state, GPIO_PV_LOW)直接用 state 作为 GPIO 编号点亮对应颜色的灯（低电平点亮）
state++ / state % 3每 0.5 秒切换状态；state%3 把数值限制为 0、1、2，刚好与软件 GPIO 对应

3. 关键技巧

① 先关闭再点亮：由于不清楚具体上一次亮的是哪个灯，所以在每次设置灯的颜色前都把 RGB 灯关闭，避免颜色残留或串色。

② state 直接当引脚编号：软件 GPIO 编号恰好是 0、1、2，与 state 取值一一对应，因此 gpiohs_set_pin(state, GPIO_PV_LOW) 一行就能点亮对应颜色，简洁且不易写错。

③ 取模循环：state = state % 3; 把 state 的值限制为 0、1、2，实现三色循环；这是"状态机 + 取模"控制循环变化的常见写法。

实验总结要点：① RGB 灯与 LED 灯的点亮原理是一样的；② 高速 GPIOHS 每个 IO 都有单独的中断源，而通用 GPIO 是共享一个总中断源。

拓展M3-X1

拓展任务：让 RGB 灯玩出更多颜色

选做

拓展 1：改变切换速度

把 msleep(500) 改为 msleep(200)（0.2 秒）观察切换变快；再改为 msleep(1000)（1 秒）观察变慢。思考：msleep 的单位是什么？太快时人眼能看到什么现象？

拓展 2：两色合成新颜色

在 rgb_all_off() 之后连续点亮两路，例如：

gpiohs_set_pin(RGB_R_GPIONUM, GPIO_PV_LOW);
gpiohs_set_pin(RGB_G_GPIONUM, GPIO_PV_LOW);
观察 RGB 灯显示的颜色。想一想：红 + 绿 → 什么颜色？红 + 蓝、绿 + 蓝呢？这验证了"不同亮度组合"的原理。

拓展 3：自己合成"黄色"状态

参考 state%3 的写法，把状态扩展为 4 个：0=红、1=绿、2=蓝、3=黄（红+绿同时亮），循环间隔仍为 0.5 秒。提示：state%3 要改为 state%4，并且 state==3 时点亮两路。

拓展 4（进阶）：按键切换颜色

利用 gpiohs_get_pin() 读取按键电平，按下一次切换一种颜色。进阶提示：用 gpiohs_irq_register() 注册中断，体验 GPIOHS"每个 IO 单独中断源"的优势。可参考 SDK 中 gpiohs 中断示例。

拓展 5（预告）：亮度渐变与更多颜色

三颗 LED 只有"亮/灭"两种状态只能得到 8 种颜色组合；要显示更多颜色需要连续调节每路的亮度——这属于 PWM（脉冲宽度调制），将在后续模块学习。提前思考：如果每路亮度有 256 级，三路可以组合出多少种颜色？

完成标准：至少完成拓展 1–3 中的两个，并在活页空白处记录每种改动的现象；拓展 4–5 可作为小组探究课题。
