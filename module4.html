实验准备与硬件连接

约 15 分钟

1. 实验元件

本实验使用的元件是开发板上的独立按键 BOOT 和 RGB 灯，出厂默认已经焊接好，无需额外接线。

BOOT 按键
独立按键（输入设备）
RGB 灯
红/绿/蓝三色（输出设备）
电平特性
按下低电平，松开高电平

2. 元件特性

独立按键 BOOT 按下时 IO 口为低电平，松开为高电平。这是判断按键状态的关键：通过读取引脚电平即可知道按键是否被按下。

3. 硬件连接

K210 开发板出厂默认已经焊接好 BOOT 按键和 RGB 灯。连接关系为：按键连接的引脚为 IO16；RGB 灯 R 连接 IO6，G 连接 IO7，B 连接 IO8。

外设颜色/功能硬件引脚（IO）模式电平特征
BOOT 按键输入IO16（B12/A12 · BOOT KEY0）上拉输入按下低电平 / 松开高电平
RGB·R红IO6输出低电平点亮
RGB·G绿IO7输出低电平点亮
RGB·B蓝IO8输出低电平点亮
理解要点：按键的"上拉"意味着默认电平被电阻拉到高电平（松开=高），按下时按键接通地（低）。GPIOHS 输入模式里对应 GPIO_DM_INPUT_PULL_UP（上拉输入）。

中断机制与实验原理

约 15 分钟

1. 实验原理

BOOT 按键按下的时候会把电平拉低，松开的时候会把电平拉高。只需要检测 BOOT 按键的 IO 口的电平：如果是按下则会产生下降沿（高→低），松开会产生上升沿（低→高），以此方式检测并触发系统的中断，然后控制 RGB 灯亮或者灭。

按键按下
电平 高→低（下降沿）
→
触发外部中断
GPIOHS 中断源
→
运行回调函数
key_irq_cb 自动执行
→
控制 RGB 灯
按下红灯亮 / 松开熄灭

2. 为什么要用中断：轮询 vs 中断

对比项轮询（查询）中断
工作方式CPU 反复循环读取引脚电平，自己"查"电平变化主动"通知"CPU，自动执行回调
CPU 占用一直占用，无法做其他事平时可做其他事，事件来了才响应
实时性取决于轮询间隔边沿一出现立即响应
适用场景简单、低速、任务单一多任务、要求实时响应
记忆锚点：轮询是"你不停问我"，中断是"有事你叫我"。嵌入式系统里外部事件（按键、传感器、通信数据）通常用中断处理。
知识活页M4-T1-K3

PLIC 中断控制器与 API

约 20 分钟

1. 什么是 PLIC

PLIC（Platform-Level Interrupt Controller，平台级中断控制器），对应头文件 plic.h。PLIC 可以将任一外部中断源单独分配到每个 CPU 的外部中断上，这提供了强大的灵活性，能适应不同的应用需求。

PLIC 模块可以设置中断回调函数：当触发中断时，会自动运行中断回调函数，并且可以配置中断优先级。

2. 为用户提供的接口

API作用
plic_initPLIC 初始化外部中断
plic_irq_enable使能外部中断
plic_irq_disable禁用外部中断
plic_set_priority设置中断优先级
plic_get_priority获取中断优先级
plic_irq_register注册外部中断函数
plic_irq_deregister注销外部中断函数

3. 使用外部中断的标准流程（三步）

初始化中断控制器：plic_init();——PLIC 初始化外部中断。
使能全局中断：sysctl_enable_irq();——打开系统全局中断开关（头文件 sysctl.h）。
注册中断回调：gpiohs_irq_register(...);——把按键的 GPIO 中断绑定到回调函数。
实验总结要点：使用外部中断前需要先初始化 PLIC 以及使能全局中断服务；这两个初始化不完成，注册的回调不会被执行。

pin_config.h 配置解析

约 15 分钟

1. 文件作用

与模块三一样的三层宏定义，本模块在 RGB 三路之外新增了一路按键映射：硬件引脚 PIN_KEY（IO16）→ 软件 GPIO KEY_GPIONUM（3）→ 功能 FUNC_KEY（FUNC_GPIOHS0 + 3）。

HARDWARE-PIN
IO6 / IO7 / IO8 / IO16
→
SOFTWARE-GPIO
GPIOHS 0 / 1 / 2 / 3
→
FUNC-GPIO
FUNC_GPIOHS0 + 编号

2. 完整源码

/**
* @file         pin_config.c
* @brief        硬件引脚与软件GPIO的宏定义
*/
#ifndef _PIN_CONFIG_H_
#define _PIN_CONFIG_H_
/*****************************HEAR-FILE************************************/
#include "fpioa.h"

/*****************************HARDWARE-PIN*********************************/
// 硬件IO口，与原理图对应
#define PIN_RGB_R             (6)
#define PIN_RGB_G             (7)
#define PIN_RGB_B             (8)

#define PIN_KEY               (16)

/*****************************SOFTWARE-GPIO********************************/
// 软件GPIO口，与程序对应
#define RGB_R_GPIONUM          (0)
#define RGB_G_GPIONUM          (1)
#define RGB_B_GPIONUM          (2)

#define KEY_GPIONUM            (3)

/*****************************FUNC-GPIO************************************/
// GPIO口的功能，绑定到硬件IO口
#define FUNC_RGB_R             (FUNC_GPIOHS0 + RGB_R_GPIONUM)
#define FUNC_RGB_G             (FUNC_GPIOHS0 + RGB_G_GPIONUM)
#define FUNC_RGB_B             (FUNC_GPIOHS0 + RGB_B_GPIONUM)

#define FUNC_KEY               (FUNC_GPIOHS0 + KEY_GPIONUM)

#endif /* _PIN_CONFIG_H_ */

3. 宏含义对照（新增部分）

宏值含义
PIN_KEY16BOOT 按键的硬件引脚号（对应原理图 IO16）
KEY_GPIONUM3按键的软件 GPIOHS 编号（程序操作对象）
FUNC_KEYFUNC_GPIOHS0+3按键的 GPIOHS 功能（绑定到硬件 IO16）
理解要点：按键与 RGB 共用同一组 GPIOHS（0–3 号），功能宏都用 FUNC_GPIOHS0 作基址——编号只要不冲突即可，硬件引脚与软件编号可以任意对应。

main.c 主程序解析

约 20 分钟

1. 完整源码

#include "pin_config.h"
#include "sleep.h"
#include "gpiohs.h"
#include "sysctl.h"
#include "plic.h"

uint32_t g_count;  // 全局计数变量，传给中断回调

/**
* @brief 硬件初始化，绑定GPIO口
*/
void hardware_init(void)
{
    // fpioa映射
    fpioa_set_function(PIN_RGB_R, FUNC_RGB_R);
    fpioa_set_function(PIN_RGB_G, FUNC_RGB_G);
    fpioa_set_function(PIN_RGB_B, FUNC_RGB_B);

    fpioa_set_function(PIN_KEY, FUNC_KEY);
}

/**
* @brief RGB灯灭
*/
void rgb_all_off(void)
{
    gpiohs_set_pin(RGB_R_GPIONUM, GPIO_PV_HIGH);
    gpiohs_set_pin(RGB_G_GPIONUM, GPIO_PV_HIGH);
    gpiohs_set_pin(RGB_B_GPIONUM, GPIO_PV_HIGH);
}

/**
* @brief 初始化RGB灯（与模块三相同）
*/
void init_rgb(void)
{
    /* 设置RGB灯的GPIO模式为输出 */
    gpiohs_set_drive_mode(RGB_R_GPIONUM, GPIO_DM_OUTPUT);
    gpiohs_set_drive_mode(RGB_G_GPIONUM, GPIO_DM_OUTPUT);
    gpiohs_set_drive_mode(RGB_B_GPIONUM, GPIO_DM_OUTPUT);

    /* 关闭RGB灯 */
    rgb_all_off();
}

/**
* @brief 按键key中断回调函数
* @param  ctx 回调参数（传入自定义类型）
*/
int key_irq_cb(void* ctx)
{
    gpio_pin_value_t key_state = gpiohs_get_pin(KEY_GPIONUM);
    /* 这里只是为了测试才在中断回调打印数据，正常情况下是不建议这么做的。*/
    printf("IRQ The PIN is %d
", key_state);

    uint32_t *tmp = (uint32_t *)(ctx);
    printf("count is %d
", (*tmp)++);

    if (!key_state)
        gpiohs_set_pin(RGB_R_GPIONUM, GPIO_PV_LOW);
    else
        gpiohs_set_pin(RGB_R_GPIONUM, GPIO_PV_HIGH);
    return 0;
}

/**
* @brief 初始化按键key
*/
void init_key(void)
{
    /* 设置按键的GPIO模式为上拉输入 */
    gpiohs_set_drive_mode(KEY_GPIONUM, GPIO_DM_INPUT_PULL_UP);
    /* 设置按键的GPIO电平触发模式为上升沿和下降沿 */
    gpiohs_set_pin_edge(KEY_GPIONUM, GPIO_PE_BOTH);
    /* 设置按键GPIO口的中断回调 */
    gpiohs_irq_register(KEY_GPIONUM, 1, key_irq_cb, &g_count);
}

/**
* @brief 主函数，程序的入口
*/
int main(void)
{
    // 硬件引脚初始化
    hardware_init();

    /* 外部中断初始化 */
    plic_init();
    /* 使能全局中断 */
    sysctl_enable_irq();

    // 初始化RGB灯
    init_rgb();

    // 初始化按键key
    init_key();

    while (1);  // 必须，否则系统退出不再运行
    return 0;
}

2. 逐段解读

代码段作用
#include "plic.h" / "sysctl.h"PLIC 中断控制器与系统控制（使能全局中断）头文件
uint32_t g_count;全局计数变量，把地址传给中断回调做参数（演示自定义参数）
hardware_init()FPIOA 映射：RGB 三路 + 按键一路（fpioa_set_function × 4）
plic_init() / sysctl_enable_irq()初始化 PLIC 外部中断 + 使能全局中断（中断能生效的前提）
init_key()按键初始化三步：上拉输入 → 双沿触发 → 注册回调
key_irq_cb(void* ctx)中断回调：读按键电平→打印信息→按下点亮红灯/松开熄灭→返回 0
while (1);死循环阻塞：中断是异步的，主程序等待即可（必须保留）

3. init_key 三步详解

设置上拉输入：gpiohs_set_drive_mode(KEY_GPIONUM, GPIO_DM_INPUT_PULL_UP)——按键是输入设备，且默认被上拉到高电平。
设置触发边沿：gpiohs_set_pin_edge(KEY_GPIONUM, GPIO_PE_BOTH)——上升沿和下降沿都触发中断（按下、松开各触发一次）。
注册中断回调：gpiohs_irq_register(KEY_GPIONUM, 1, key_irq_cb, &g_count)——参数含义：GPIO 编号、优先级 1、回调函数、传给回调的参数（&g_count）。

4. 关键技巧：回调参数

回调函数声明为 int key_irq_cb(void* ctx)，在注册时传入 &g_count，回调内用 uint32_t *tmp = (uint32_t *)(ctx); 取出并自增。这样可以在中断回调中传入自己需要的任何类型参数，非常灵活。

实验总结要点：① BOOT 按键与 RGB 同样适用 GPIOHS 函数，只是按键使用输入模式、RGB 使用输出模式；② 使用外部中断前需要先初始化 PLIC 以及使能全局中断服务；③ 中断回调函数中可以传入一个参数，参数类型可以传入自己需要的类型。

3. 现象与代码对应（口述自检）

按/松按键产生边沿 → gpiohs_irq_register 注册的回调 key_irq_cb 自动执行 → gpiohs_get_pin 读到 0（按下）则红灯低电平点亮、读到 1（松开）则高电平熄灭；count 通过回调参数 ctx（&g_count）每次加 1。

拓展M4-X1

拓展任务：让按键控制更有趣

选做

拓展 1：只响应按下（单沿触发）

把 gpiohs_set_pin_edge(KEY_GPIONUM, GPIO_PE_BOTH) 改为 GPIO_PE_FALLING（只下降沿触发）。思考：现在按一次、松一次各触发几次中断？松开时红灯还灭吗？（提示：回调只在下按时执行。）

拓展 2：按键控制绿灯 / 蓝灯

把回调里的 RGB_R_GPIONUM 分别改为 RGB_G_GPIONUM、RGB_B_GPIONUM，观察按下时亮的是什么颜色。想一想：RGB 三路与按键四路共用 GPIOHS 0–3，如何保证互不干扰？

拓展 3：按键切换三色（状态机）

结合模块三的"状态"思路：在回调里让 state++ 并对 3 取模，每次按下切换红/绿/蓝一种颜色亮。提示：可借助回调参数 ctx 传入 state 的地址，或直接使用全局变量。

拓展 4（进阶）：长按计数控制

利用 count 计数：当 count 达到 3 的倍数时点亮蓝灯，否则红灯。体会"回调里做简单逻辑、复杂逻辑放主循环"的取舍——思考为什么中断回调里不建议做耗时操作。

拓展 5（预告）：更多按键与矩阵键盘

本模块只有一个 BOOT 按键。如果要接 4×4 矩阵键盘（16 个按键只占 8 个 IO），该如何扫描与识别？这属于 GPIO 输入的高级应用，将在后续综合项目中使用。提前思考：轮询和中断哪种更适合矩阵键盘？

完成标准：至少完成拓展 1–3 中的两个，并在活页空白处记录每种改动的现象；拓展 4–5 可作为小组探究课题。
