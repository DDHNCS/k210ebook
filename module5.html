模块五 · 定时器（定时器配置与定时中断）

前四个模块用 GPIO 点亮了 LED 与 RGB、用外部中断"听"到了按键。本模块引入时间维度：用 K210 片内定时器每 0.5 秒自动触发一次中断，让 RGB 灯白光亮灭循环；再用 BOOT 按键中断去控制定时器的使能与停止，体验"定时中断 + 按键控制"的组合。

配套课程：图像识别技术（边缘计算 & 机器视觉） 建议学时：2 学时 前置模块：模块一 / 模块二 / 模块三 / 模块四 硬件平台：Kendryte K210 开发板
开始学习 查看活页索引

模块总体设计

本模块在按键中断基础上引入"时间"维度：定时器作为"自动的节拍器"，每隔固定时间主动触发中断；按键中断作为"手动开关"，控制节拍的启停。这是嵌入式系统实现周期性任务的典型方式。

2. 元件特性

K210 芯片定时器总共有 3 个，每个定时器有 4 路通道。每个定时器可以设置触发间隔，和定时器中断处理函数。实验中用到的就是其中一个定时器的其中一路通道。

记忆锚点："3 个定时器 × 4 路通道"——共 12 路定时通道，互不干扰，可以分别设置不同的触发间隔与回调。

3. 硬件连接

K210 开发板出厂默认已经焊接好 BOOT 按键和 RGB 灯。连接关系为：按键连接的引脚为 IO16；RGB 灯 R 连接 IO6，G 连接 IO7，B 连接 IO8。定时器在芯片内部，不占用外部引脚。

知识活页M5-T1-K2

定时器工作原理

约 15 分钟

1. 加 1 计数器原理

定时器的核心其实是加 1 计数器：它对机器周期进行计数，每过一个机器周期，计数器自动加 1，直到计数器计满溢出。由于计数的周期是固定的，所以根据计数的多少就可以很方便地计算出计数的时间。当符合自己设定的超时时间时，则调用中断回调函数，然后重新开始计数。

机器周期计数
计数器自动 +1
→
计满超时时间
到达设定的间隔
→
触发定时器中断
调用回调函数
→
重新开始计数
循环往复

用"秒表"来类比：机器周期就像秒表的最小刻度，超时时间就是"倒计时到 0 就响铃"的设定值，响铃（中断）后秒表自动重新开始计时。

2. 定时器中断 vs 软件延时

对比项软件延时（如 msleep）定时器中断
工作方式CPU 空等，时间到才继续执行CPU 先做别的事，到点自动触发回调
CPU 占用延时期间 CPU 被占用，无法做其他事不占用，回调执行完继续主流程
计时精度依赖系统节拍，误差较大可设置纳秒级别超时时间
适用场景简单顺序流程周期性任务、多任务并行
理解要点：定时器实现的是周期性任务（每隔固定时间做一次），而软件延时只能"阻塞地等一次"。本实验每 0.5 秒切换一次 RGB 状态，用定时器可以让 CPU 一边等待按键、一边完成闪烁。

timer.h API 与定时器资源

约 20 分钟

1. 定时器资源

K210 共有 3 个定时器（TIMER_DEVICE_0 / 1 / 2），每个定时器有 4 路通道（TIMER_CHANNEL_0 ~ 3）。本实验使用定时器 0 的通道 0。

2. 为用户提供的接口（头文件 timer.h）

API作用
timer_init初始化定时器
timer_set_interval设置定时间隔
timer_set_irq0.6.0 后不再支持，请使用 timer_irq_register

版本提示：旧版 API timer_set_irq 在 SDK 0.6.0 之后不再支持，统一改用 timer_irq_register 注册中断回调。

3. 定时器使用流程（四步）

初始化定时器：timer_init(TIMER_DEVICE_0);——指定使用哪个定时器。
设置超时时间：timer_set_interval(TIMER_DEVICE_0, TIMER_CHANNEL_0, 500 * 1e6);——单位纳秒，500*1e6 即 0.5 秒。
注册中断回调：timer_irq_register(TIMER_DEVICE_0, TIMER_CHANNEL_0, 0, 1, timer_timeout_cb, &g_count);——通道、参数、优先级、回调与自定义参数。
使能定时器：timer_set_enable(TIMER_DEVICE_0, TIMER_CHANNEL_0, 1);——1 启动、0 停止。
实验总结要点：① 定时器可以设置纳秒级别的超时时间，并且可以设置中断回调；② 定时器可以通过控制使能与禁止的方式来暂停和重新启动，而不需要重新配置；③ K210 总共有三个定时器，每个定时器有四个通道。

main.c 完整源码解析

约 20 分钟

1. 完整源码

#include "pin_config.h"
#include "sleep.h"
#include "gpiohs.h"
#include "sysctl.h"
#include "plic.h"
#include "timer.h"

uint32_t g_count;  // 全局计数变量，传给定时器中断回调

/**
* @brief 硬件初始化，绑定GPIO口
*/
void hardware_init(void)
{
    /* fpioa映射 */
    fpioa_set_function(PIN_RGB_R, FUNC_RGB_R);
    fpioa_set_function(PIN_RGB_G, FUNC_RGB_G);
    fpioa_set_function(PIN_RGB_B, FUNC_RGB_B);

    fpioa_set_function(PIN_KEY, FUNC_KEY);
}

/**
* @brief RGB灯灭
*/
void rgb_all_off(void)
{
    gpiohs_set_pin(RGB_R_GPIONUM, GPIO_PV_HIGH);
    gpiohs_set_pin(RGB_G_GPIONUM, GPIO_PV_HIGH);
    gpiohs_set_pin(RGB_B_GPIONUM, GPIO_PV_HIGH);
}

/**
* @brief RGB灯亮白灯
* @note  RGB灯内部三种颜色的灯一起亮就变为白色
*/
void rgb_all_on(void)
{
    gpiohs_set_pin(RGB_R_GPIONUM, GPIO_PV_LOW);
    gpiohs_set_pin(RGB_G_GPIONUM, GPIO_PV_LOW);
    gpiohs_set_pin(RGB_B_GPIONUM, GPIO_PV_LOW);
}

/**
* @brief 初始化RGB灯（与模块三、四相同）
*/
void init_rgb(void)
{
    /* 设置RGB灯的GPIO模式为输出 */
    gpiohs_set_drive_mode(RGB_R_GPIONUM, GPIO_DM_OUTPUT);
    gpiohs_set_drive_mode(RGB_G_GPIONUM, GPIO_DM_OUTPUT);
    gpiohs_set_drive_mode(RGB_B_GPIONUM, GPIO_DM_OUTPUT);

    /* 关闭RGB灯 */
    rgb_all_off();
}

/**
* @brief 按键key中断回调函数（模块四基础上修改）
* @note  根据按键状态控制定时器的使能与停止
*/
int key_irq_cb(void* ctx)
{
    gpio_pin_value_t key_state = gpiohs_get_pin(KEY_GPIONUM);

    if (key_state)
        timer_set_enable(TIMER_DEVICE_0, TIMER_CHANNEL_0, 1);
    else
        timer_set_enable(TIMER_DEVICE_0, TIMER_CHANNEL_0, 0);
    return 0;
}

/**
* @brief 初始化按键key（与模块四相同）
*/
void init_key(void)
{
    // 设置按键的GPIO模式为上拉输入
    gpiohs_set_drive_mode(KEY_GPIONUM, GPIO_DM_INPUT_PULL_UP);
    // 设置按键的GPIO电平触发模式为上升沿和下降沿
    gpiohs_set_pin_edge(KEY_GPIONUM, GPIO_PE_BOTH);
    // 设置按键GPIO口的中断回调
    gpiohs_irq_register(KEY_GPIONUM, 1, key_irq_cb, NULL);
}

/**
* @brief 定时器中断回调
* @note  每次中断切换RGB灯亮白或熄灭
*/
int timer_timeout_cb(void *ctx) {
    uint32_t *tmp = (uint32_t *)(ctx);
    (*tmp)++;
    if ((*tmp)%2)
    {
        rgb_all_on();
    }
    else
    {
        rgb_all_off();
    }
    return 0;
}

/**
* @brief 初始化定时器
*/
void init_timer(void) {
    /* 定时器初始化 */
    timer_init(TIMER_DEVICE_0);
    /* 设置定时器超时时间，单位为ns */
    timer_set_interval(TIMER_DEVICE_0, TIMER_CHANNEL_0, 500 * 1e6);
    /* 设置定时器中断回调 */
    timer_irq_register(TIMER_DEVICE_0, TIMER_CHANNEL_0, 0, 1, timer_timeout_cb, &g_count);
    /* 使能定时器 */
    timer_set_enable(TIMER_DEVICE_0, TIMER_CHANNEL_0, 1);
}

/**
* @brief 主函数，程序的入口
*/
int main(void)
{
    /* 硬件引脚初始化 */
    hardware_init();

    /* 初始化系统中断并使能 */
    plic_init();
    sysctl_enable_irq();

    /* 初始化RGB灯 */
    init_rgb();

    /* 初始化按键key */
    init_key();

    /* 初始化定时器 */
    init_timer();

    while (1);

    return 0;
}

2. 整体流程

初始化顺序为：FPIOA 映射 → PLIC 与全局中断 → RGB → 按键 → 定时器。定时器初始化放在最后，因为它依赖前面已经就绪的 RGB（回调要操作灯）与按键（回调要控制它）。

知识活页M5-T2-K2

关键代码详解

约 20 分钟

1. 按键中断：控制定时器启停

模块四的回调里直接操作 RGB 灯，本模块改为操作定时器：

读取按键状态：key_state = gpiohs_get_pin(KEY_GPIONUM)——按下为 0，松开为 1。
松开（key_state 为真）→ 使能定时器：timer_set_enable(TIMER_DEVICE_0, TIMER_CHANNEL_0, 1)——定时器开始计时，RGB 每 0.5 秒切换一次。
按下（key_state 为 0）→ 停止定时器：timer_set_enable(TIMER_DEVICE_0, TIMER_CHANNEL_0, 0)——定时器暂停，RGB 保持当前状态。
理解要点：使能/禁止（0/1）只是暂停与恢复，定时器的超时时间、回调等配置不需要重新设置——这就是实验总结第 (2) 条的工程价值。

2. 定时器中断回调：白灯闪烁

timer_timeout_cb 每 0.5 秒执行一次：计数变量 g_count 每次加 1；奇数次调用 rgb_all_on() 点亮白灯，偶数次调用 rgb_all_off() 熄灭——实现"亮 0.5 秒 → 灭 0.5 秒"的循环。

(*tmp)++;中断次数加 1

else rgb_all_off();偶数次熄灭

3. 白灯是怎么来的

RGB 灯内部三种颜色的灯一起亮就变为白色。rgb_all_on() 把三路 GPIO 全部设为低电平（点亮），rgb_all_off() 全部设为高电平（熄灭）。

拓展M5-X1

拓展任务：玩转定时器参数

选做

拓展 1：改变闪烁速度

把 500 * 1e6 分别改为 250 * 1e6（0.25 秒）与 1000 * 1e6（1 秒），观察白灯闪烁快慢的变化。思考：定时器间隔变短对 CPU 和中断频率有什么影响？

拓展 2：换一个定时器/通道

把 TIMER_DEVICE_0 改为 TIMER_DEVICE_1，或把 TIMER_CHANNEL_0 改为 TIMER_CHANNEL_1，验证 K210 的多定时器、多通道资源是否可独立工作。

拓展 3：四态循环（状态机）

在 timer_timeout_cb 里用 (*tmp) % 4 代替 % 2，实现"白灯亮 → 灭 → 红灯亮 → 灭"四态循环。提示：红灯亮只把 R 一路设为低电平，其他两路保持高电平。

拓展 4（进阶）：双定时器并行

再加一路定时器（如定时器 1 通道 0，间隔 1 秒）驱动绿灯闪烁，与原有的 0.5 秒白灯并行运行。体会"多个定时通道互不干扰、各管各的任务"的多任务思路。

拓展 5（预告）：定时器用于周期采样

定时器最典型的应用是周期采样：每隔固定时间读取一次传感器数据。想一想：如果以后要每 200ms 读取一次温湿度并判断是否超限，用定时器中断还是软件延时更合适？为什么？

完成标准：至少完成拓展 1–3 中的两个，并在活页空白处记录每种改动的现象；拓展 4–5 可作为小组探究课题。
