实验准备与硬件连接

约 15 分钟

1. 实验元件

本实验使用的元件是开发板上的 LCD 显示屏，出厂默认已经安装好，无需额外接线。

LCD 显示屏
2.0 寸 · 320×240
驱动芯片
ST7789
通信接口
SPI 高速串行总线

2. 元件特性

LCD 显示为 2.0 寸，分辨率为 320×240，驱动芯片是 ST7789，体积小、厚度薄、耗能低，工作电压为 3.3V，显示屏的材料为 TFT。

TFT（Thin Film Transistor，薄膜晶体管）是指：使每个液晶像素点都是由集成在像素点后面的薄膜晶体管来驱动，从而可以做到高速度、高亮度、高对比度地显示屏幕信息。

记忆锚点："2 寸、320×240、ST7789、TFT、3.3V"——五要素。分辨率 320（宽）× 240（高），与图片 API 的 width/height 上限一致。

3. 硬件连接

K210 开发板出厂默认已经安装好 LCD 显示屏，其中 LCD_D0~D7 总共八个引脚连接到 SPI0_D0~D7 上，LCD_CS 连接到 IO36 上，LCD_RST 连接到 IO37 上，LCD_RS 连接到 IO38 上，LCD_WR 连接到 IO39 上。

LCD_D0~D7数据线 × 8SPI0_D0~D7SPI0 数据（八线模式）
LCD_CS片选IO36FUNC_SPI0_SS3
LCD_RST复位IO37FUNC_GPIOHS0+0
LCD_RS命令/数据选择IO38FUNC_GPIOHS0+1

液晶显示原理

约 15 分钟

1. 液晶显示的基本原理

LCD 显示的基本原理是：将液晶置于两片导电玻璃基板之间，在上下玻璃基板的两个电极作用下，引起液晶分子扭曲变形，改变通过液晶盒光束的偏振状态，实现对背光源光束的开关控制。

不加电场
偏振光随液晶分子扭曲 90° → 透光
→
施加电压
液晶分子沿电场方向再排列 → 改变透光
→
电压大小
决定亮度，子图元颜色由筛检程序决定

2. TN 型液晶的工作细节

如果液晶盒上不施加外电场，由于 TN 型液晶显示器件中液晶分子在盒中的扭曲螺距远比可见光波长大得多，所以当入射直线偏振光的偏振方向与玻璃表面液晶分子的排列方向一致时，其偏光方向在通过整个液晶层后会随着液晶分子扭曲变形而被扭曲 90°，由另一侧射出，呈透光状态。

如果这时在液晶盒上施加一个电压并达到一定值后，液晶分子长轴将开始沿电场方向倾斜，除电极表面的液晶分子外，所有液晶盒内两电极之间的液晶分子都变成沿电场方向的再排列。

理解要点：液晶显示屏技术是根据电压的大小来改变亮度；每个液晶显示屏的子图元显示的颜色取决于色彩筛检程序（RGB 三基色子像素按比例组合出各种颜色）。
知识活页M6-T1-K3

SPI 通信原理与 API

约 20 分钟

1. 什么是 SPI

SPI 是一种高速、高效率的串行接口技术，通常由一个主模块和一个或多个从模块组成，主模块选择一个从模块进行同步通信，从而完成数据的交换。SPI 是一个环形结构，通信时需要至少 4 根线（事实上在单向传输时 3 根线也可以）。

信号线全称作用
MISOMaster Input Slave Output主设备数据输入，从设备数据输出
MOSIMaster Output Slave Input主设备数据输出，从设备数据输入
SCLKSerial Clock时钟信号，由主设备产生
CSChip Select从设备使能信号，由主设备控制（低电平选中）
多从设备：当有多个从设备时，每个从设备都有一个片选引脚接入主设备；主设备与某个从设备通信时，需要将该从设备对应的片选引脚电平拉低或拉高。

pin_config.h 与 main.c 解析

约 20 分钟

1. pin_config.h 配置

LCD 的四个控制引脚：CS（片选）、RST（复位）、RS（命令/数据选择）、WR（写时钟）。其中 CS 与 WR 直接映射到 SPI 功能，RST 与 RS 使用 GPIOHS 控制。

/*****************************HARDWARE-PIN*********************************/
// 硬件IO口，与原理图对应
#define PIN_LCD_CS              (36)
#define PIN_LCD_RST             (37)
#define PIN_LCD_RS              (38)
#define PIN_LCD_WR              (39)

/*****************************SOFTWARE-GPIO********************************/
#define LCD_RST_GPIONUM         (0)
#define LCD_RS_GPIONUM          (1)

/*****************************FUNC-GPIO************************************/
// GPIO口的功能，绑定到硬件IO口
#define FUNC_LCD_CS             (FUNC_SPI0_SS3)
#define FUNC_LCD_RST            (FUNC_GPIOHS0 + LCD_RST_GPIONUM)
#define FUNC_LCD_RS             (FUNC_GPIOHS0 + LCD_RS_GPIONUM)
#define FUNC_LCD_WR             (FUNC_SPI0_SCLK)
宏值含义
PIN_LCD_CS → FUNC_LCD_CS36 → FUNC_SPI0_SS3片选映射为 SPI0 第 3 路从设备选择
PIN_LCD_WR → FUNC_LCD_WR39 → FUNC_SPI0_SCLK写时钟映射为 SPI0 时钟线
PIN_LCD_RST → FUNC_LCD_RST37 → GPIOHS0+0复位引脚用 GPIO 软件控制
PIN_LCD_RS → FUNC_LCD_RS38 → GPIOHS0+1命令/数据选择用 GPIO 软件控制

2. main.c 完整源码

#include "sleep.h"
#include "gpiohs.h"
#include "lcd.h"
#include "st7789.h"
#include "sysctl.h"
#include "pin_config.h"

/**
* @brief 设置bank6的电源域1.8V
*/
void io_set_power(void)
{
    sysctl_set_power_mode(SYSCTL_POWER_BANK6, SYSCTL_POWER_V18);
}

/**
* @brief 硬件初始化，绑定GPIO口
*/
void hardware_init(void)
{
    fpioa_set_function(PIN_LCD_CS,  FUNC_LCD_CS);
    fpioa_set_function(PIN_LCD_RST, FUNC_LCD_RST);
    fpioa_set_function(PIN_LCD_RS,  FUNC_LCD_RS);
    fpioa_set_function(PIN_LCD_WR,  FUNC_LCD_WR);

    /* 使能SPI0和DVP数据 */
    sysctl_set_spi0_dvp_data(1);
}

/**
* @brief 主函数，程序的入口
*/
int main(void)
{
    /* 硬件引脚初始化 */
    hardware_init();

    /* 设置IO口电压 */
    io_set_power();

    /* 初始化LCD */
    lcd_init();

    /* 显示图片：起点(0,0)，宽320，高240 */
    lcd_draw_picture_half(0, 0, 320, 240, gImage_logo);
    sleep(1);

    /* 显示字符：起点(16,40)红色 / (16,60)蓝色 */
    lcd_draw_string(16, 40, "Hello HNSWXY!", RED);
    lcd_draw_string(16, 60, "Nice to meet you!", BLUE);

    while (1);
    return 0;
}

3. 主流程解读

硬件映射：hardware_init()——四个控制引脚映射 + sysctl_set_spi0_dvp_data(1) 使能 SPI0 数据通路。
IO 电压：io_set_power()——设置 bank6 电源域为 1.8V（LCD 的 IO 电平要求）。
初始化屏幕：lcd_init()——激活 LCD、设置方向与颜色格式、使能显示并清屏。
显示图片：lcd_draw_picture_half(0, 0, 320, 240, gImage_logo)——全屏显示 logo 图，sleep(1) 停留 1 秒。
显示字符串：两行 lcd_draw_string——红色与蓝色欢迎语。
保持：while (1)——必须，否则系统退出屏幕消失。
教材与工程差异：教材通用示例的欢迎语为 "Hello Yahboom!"；本工程源码定制为 "Hello HNSWXY!"，烧录后以工程源码实际显示为准。

关键代码详解

约 20 分钟

1. lcd_init()：初始化七步

初始化 LCD，主要的功能就是激活 LCD 显示屏，设置显示方向和显示颜色，并使能显示和清空显示屏。关于详细的 ST7789 初始化寄存器对应和功能，可查看硬件资料中的 LCD 资料（ST7789 开发手册）。

硬件初始化：tft_hard_init()——GPIO 控制 RS/RST + spi_init(SPI_CHANNEL, SPI_WORK_MODE_0, SPI_FF_OCTAL, 8, 0)（八线模式、8 位宽）+ spi_set_clk_rate(SPI_CHANNEL, 20000000)（20MHz）。
软复位：tft_write_command(SOFTWARE_RESET)，等待 100ms。
关睡眠：tft_write_command(SLEEP_OFF)，等待 100ms。
像素格式：PIXEL_FORMAT_SET + 数据 0x55——65K 色、16bit/pixel（RGB565）。
显示反转：INVERSION_DISPLAY_ON——打开显示反转。
显示方向：lcd_set_direction(DIR_YX_LRUD)——设置显示方向，同时确定宽高（320/240 或交换）。
使能与清屏：DISPLAY_ON + lcd_clear(WHITE)——白屏清空。

2. ST7789 底层 SPI 驱动

ST7789 底层驱动负责"开始传输命令/数据"与"SPI 写命令/数据"：tft_write_command 先把 RS 拉低（命令模式），再用 spi_init_non_standard 设置指令长度 8 位，最后 spi_send_data_normal_dma 发送命令字节；写数据时 RS 拉高，用 32 位地址模式批量发送像素。

底层函数作用
tft_hard_initGPIO 初始化 RS/RST，SPI 八线模式 8 位宽，时钟 20MHz
tft_write_commandRS 拉低 → SPI 发送命令字节（指令长度 8 位）
tft_write_byte / half / wordRS 拉高 → 批量发送 8/16/32 位数据（像素）
tft_fill_dataDMA 持续发送同一数据，用于清屏/填充

3. 显示图片 API

lcd_draw_picture_half(x1, y1, width, height, ptr)：x1 和 y1 是起点位置，width 为图片的宽度（最大 320），height 为图片的高度（最大 240），ptr 指针指向要显示的图片。内部实现为 lcd_set_area(x1, y1, x1+width-1, y1+height-1) 划定区域，再 tft_write_half(ptr, width*height) 把像素数据写进屏幕。

4. 显示字符串 API

lcd_draw_string(x, y, str, color)：x 和 y 为起始坐标，str 指针指向要显示的字符串，color 为字体的颜色。内部逐个字符调用 lcd_draw_char，每画一个字符 x += 8（每个字符宽 8 像素），字体点阵来自 font.h。

5. 图片数据是怎么来的（Image2Lcd）

图片转化为数据格式的方法：安装并打开图片转化工具 Image2Lcd，按工具配置（320×240、RGB565、输出 C 数组），把保存得到的 .c 文件（如 logo.c）复制到项目目录下，然后通过 extern 关键字在要使用的地方引用（extern const unsigned char gImage_logo[153608];）。

实验总结要点：① LCD 显示屏分辨率是 320×240，显示图片前需要把图片转化成 320×240 分辨率，然后通过图片转化工具把图片转成 .c 文件，再引用图片的变量即可；② LCD 是基于 SPI 通讯的，传输速度快并且稳定；③ 显示屏在显示前需要配置显示的方向以及显示的格式等参数。
