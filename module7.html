2. 元件特性

K210 开发板自带 2.0 寸触摸屏，其实是 LCD 显示屏上贴一个触摸板组成，LCD 显示屏上一节课已经学过，而触摸板为电容触摸板，与手机上使用的电容屏原理一样，可以直接用手指触摸，而不像电阻屏一样要用指甲按。

电容屏具有响应时间短、精确度高、使用寿命长、操作简单方便等特点。触摸板使用的是 I2C 通讯，能够稳定传输数据，并且支持与其他 I2C 设备并联到同一个 I2C 接口上通讯。

记忆锚点：电容屏"指腹轻触"、电阻屏"指甲按压"；电容屏用 I2C 两线，可多设备共总线。

3. 硬件连接

LCD 连接与模块六相同（LCD_D0~D7→SPI0_D0~D7、CS→IO36、RST→IO37、RS→IO38、WR→IO39）；触摸板的 I2C_SCL 连接到 IO9，I2C_SDA 连接到 IO10，FT_INT 连接到 IO12，FT_RST 连接到 IO37（与 LCD 显示屏共用同一个 RST 接口）。

电容触摸屏原理

约 15 分钟

1. 人体电流感应

电容式触摸屏技术是利用人体的电流感应进行工作的。电容式触摸屏是一块四层复合玻璃屏：玻璃屏的内表面和夹层各涂有一层 ITO（氧化铟锡，透明导电层），最外层是一薄层矽土玻璃保护层，夹层 ITO 涂层作为工作面，四个角上引出四个电极，内层 ITO 为屏蔽层以保证良好的工作环境。

手指触摸
人体电场形成耦合电容
→
吸走小电流
电流从接触点流出
→
四角电极分流
电流与到四角距离成正比
→
计算比例
得出触摸点位置

当手指触摸在金属层上时，由于人体电场，用户和触摸屏表面形成一个耦合电容；对于高频电流来说，电容是直接导体，于是手指从接触点吸走一个很小的电流。这个电流分别从触摸屏的四角上的电极中流出，并且流经这四个电极的电流与手指到四角的距离成正比，控制器通过对这四个电流比例的精确计算，得出触摸点的位置。

理解要点：电容屏"四点电流测距"——离哪个角近，那个角分到的电流就大；四个角的电流比例唯一确定一个触摸点 (X, Y)。

I2C 通信原理与 API

约 20 分钟

1. 什么是 I2C

I2C 是一种总线式结构，它只需要 SCL 时钟信号线与 SDA 数据线，两根线就能将连接在总线上的设备实现数据通信。由于简便的构造设计，I2C 成为一种较为常用的通信方式。I2C 总线用于和多个外部设备进行通信，多个外部设备可以共用一个 I2C 总线。

信号线作用
SCLSerial Clock，时钟信号线，由主机产生
SDASerial Data，数据线，双向传输

由于 I2C 采用的是主从式通信方式，所以通信的过程完全由主设备仲裁。在通信之前，必须由主设备发送一个起始信号，决定数据是否可以开始传送；在结束通信时，必须再由主设备发送一个结束信号，表示通信已经结束。

2. K210 的 I2C 资源

K210 芯片集成电路总线有 3 个 I2C 总线接口，都可以作为 I2C 主机（MASTER）模式或从机（SLAVE）模式来使用。I2C 接口支持标准模式（0 到 100kb/s）、快速模式（≤400kb/s）、7 位或 10 位寻址模式、批量传输模式、中断或轮询模式操作。I2C 模块具有独立的 I2C 设备封装外设相关参数、自动处理多设备总线争用的功能。

3. 为用户提供的接口（头文件 i2c.h）

#define PIN_FT_INT             (12)
#define PIN_FT_SCL             (9)

#define FT_INT_GPIONUM         (2)
#define FT_RST_GPIONUM         (3)

#define FUNC_FT_INT             (FUNC_GPIOHS0 + FT_INT_GPIONUM)

2. main.c 完整源码

#include "sleep.h"
#include "gpiohs.h"
#include "lcd.h"
#include "sysctl.h"
#include "ft6236u.h"
#include "st7789.h"
#include "pin_config.h"

extern const unsigned char gImage_logo[153608];

/**
* @brief 设置bank6的电源域1.8V
*/
void io_set_power(void)
{
    sysctl_set_power_mode(SYSCTL_POWER_BANK6, SYSCTL_POWER_V18);
}

/**
* @brief 硬件初始化，绑定GPIO口
*/
void hardware_init(void)
{
    fpioa_set_function(PIN_LCD_CS, FUNC_LCD_CS);
    fpioa_set_function(PIN_LCD_RST, FUNC_LCD_RST);
    fpioa_set_function(PIN_LCD_RS, FUNC_LCD_RS);
    fpioa_set_function(PIN_LCD_WR, FUNC_LCD_WR);

    /* 使能SPI0和DVP */
    sysctl_set_spi0_dvp_data(1);

    /* I2C FT6236：FT_RST与LCD_RST共用IO37，不需要再映射 */
    fpioa_set_function(PIN_FT_INT, FUNC_FT_INT);
    fpioa_set_function(PIN_FT_SCL, FUNC_FT_SCL);
    fpioa_set_function(PIN_FT_SDA, FUNC_FT_SDA);
}

/**
* @brief 清除坐标数据（用白色填充坐标区域）
*/
void lcd_clear_coord(void)
{
    uint32_t color = 0xFFFFFFFF;
    uint8_t x1 = 120;
    uint8_t y1 = 200;
    uint8_t width = 100;
    uint8_t height = 16;

    lcd_set_area(x1, y1, x1 + width - 1, y1 + height - 1);
    tft_fill_data(&color, width * height / 2);
}

/**
* @brief 主函数，程序的入口
*/
int main(void)
{
    /* 硬件引脚初始化 */
    hardware_init();

    /* 设置IO口电压 */
    io_set_power();

    /* 系统中断初始化，并使能全局中断 */
    plic_init();
    sysctl_enable_irq();

    /* 初始化LCD */
    lcd_init();

    /* 显示图片 */
    uint16_t * img = &gImage_logo;
    lcd_draw_picture_half(0, 0, 320, 240, img);
    sleep(1);
    lcd_draw_string(16, 40, "Hello HNSW", RED);
    lcd_draw_string(16, 60, "Nice to meet you!", BLUE);

    /* 初始化触摸板 */
    ft6236_init();
    printf("Hi!Please touch the screen to get coordinates!\n");
    lcd_draw_string(16, 180, "Please touch the screen to get coord!", RED);

    /* 显示的坐标 */
    char coord[30];
    uint8_t is_refresh = 0;

    while (1)
    {
        /* 刷新数据位，清空上次显示的数据 */
        if (is_refresh)
        {
            lcd_clear_coord();
            is_refresh = 0;
        }

        /* 如果触摸到触摸屏的时候 */
        if (ft6236.touch_state & TP_COORD_UD)
        {
            ft6236.touch_state &= ~TP_COORD_UD;
            /* 扫描触摸屏 */
            ft6236_scan();
            /* 串口打印X Y坐标 */
            printf("X=%d, Y=%d \n ", ft6236.touch_x, ft6236.touch_y);
            sprintf(coord, "(%d, %d)", ft6236.touch_x, ft6236.touch_y);

            lcd_draw_string(120, 200, coord, BLUE);
            is_refresh = 1;
        }
        /* 延迟80毫秒保证屏幕数据正常刷新 */
        msleep(80);
    }

    return 0;
}

3. 主流程解读

硬件与中断：hardware_init() → io_set_power() → plic_init() + sysctl_enable_irq()（触摸板用中断判断是否有触摸）。
显示画面：lcd_init() → 全屏图片 → 欢迎语 + 触摸提示语。
初始化触摸板：ft6236_init()——配置 FT6236 寄存器并注册 FT_INT 中断。
主循环：每 80ms 检查 TP_COORD_UD 标记 → 扫描坐标 → 串口打印 → LCD 显示 → 下次先清除旧坐标。

关键代码详解

约 20 分钟

1. FT6236 初始化（硬件 + 软件）

触摸板 FT6236 的初始化比较简单，分为硬件初始化和软件初始化。软件初始化主要是设置 FT6236 的寄存器，唤醒 FT6236、设置触摸灵敏度和扫描周期。

寄存器写入值作用
FT_DEVIDE_MODE (0x00)0x00模式控制（正常工作模式）
FT_ID_G_THGROUP (0x80)0x12触摸有效值，越小越灵敏
FT_ID_G_PERIODACTIVE (0x88)0x06工作扫描周期，控制报点率

2. I2C 读写封装（i2c_ctl.c）

函数作用
i2c_hardware_init(addr)i2c_init(I2C_DEVICE_0, addr, 7, 100000)——从机地址 0x38、7 位地址、100kb/s
i2c_hd_write(addr, reg, data)向寄存器 reg 写入一个数据 data，成功返回 0，失败返回非 0
i2c_hd_read(addr, reg, buf, len)从寄存器 reg 读取 length 个数据保存到 data_buf，成功返回 0

3. "中断标记 + 主循环处理"模式

触摸板用 FT_INT 中断判断"有没有触摸"：ft6236_hardware_init() 里把 FT_INT 设为输入模式、上升沿触发，注册中断回调 ft6236_isr_cb；回调里只做一件事——touch_state |= TP_COORD_UD（标记坐标已更新）。真正的扫描、打印、显示都在主循环里完成。

工程思想：中断回调里不做耗时操作（只置标志），复杂处理放主循环——与模块四的"回调里少做事"一脉相承。

4. ft6236_scan()：坐标换算

从 FT_REG_NUM_FINGER（0x02，触摸状态/报点个数）读到状态，若有触摸点，再从 FT_TP1_REG（0x03）读取 4 个字节坐标数据：

uint16_t temp_y = ((uint16_t)(data[0] & 0x0f) << 8) + data[1];
ft6236.touch_y = (uint16_t)(240 - temp_y);
ft6236.touch_x = ((uint16_t)(data[2] & 0x0f) << 8) + data[3];

高 4 位 + 低 8 位拼成 12 位坐标；Y 方向做了 240 - temp_y 的翻转换算（触摸板与屏幕 Y 轴方向相反）。这就是实验总结第 (2) 条说的"读取数据后需要转化计算一下才能得到实际的触摸坐标"。

5. 坐标显示与刷新（lcd_clear_coord）

主循环里每次显示坐标后置 is_refresh = 1，下一轮先 lcd_clear_coord() 清除旧坐标——用 lcd_set_area 设定显示坐标的区域，再写入白色的值（0XFFFFFFFF）刷新显示内容。如果背景图片的坐标区域不是空白的，则无法使用此方法来刷新。

实验总结要点：① K210 开发板的触摸屏是电容式触摸屏，可以使用手指直接触摸使用；② 触摸板使用的是 I2C 通讯，读取数据后需要转化计算一下才能得到实际的触摸坐标；③ 触摸板的相关寄存器放在项目的 README.md 文件中，具体寄存器功能请查看硬件相关资料中的触摸屏资料。
