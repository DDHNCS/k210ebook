模块八 · flash读写数据（Flash 存储读写控制）

前几个模块都在"用"数据，本模块学习"存"数据：K210 板载 GD25LQ128C Flash 芯片（SPI 串行闪存，16MB），先写入约 40KB 数据再读回，对比一致即成功。体验"断电不丢"的存储特性，这是保存模型参数、用户配置与识别日志的基础。

模块总体设计

Flash 是断电保存的存储介质。本模块通过 SPI3 接口读写板载 GD25LQ128C：初始化 + 读 ID 校验 → 写入缓存数据（计时）→ 读回（计时）→ 对比校验。核心体会"写按页/扇区、读任意地址、断电不丢"。

元件特性与读写规则

约 15 分钟

1. 实验元件

本实验使用的元件是开发板上板载的 flash 芯片 GD25LQ128C，通过 SPI 接口与 K210 通信，出厂已焊接在开发板上，无需额外接线。

GD25LQ128C
SPI 串行闪存 · 128M-bit
16MB 空间
储存声音、文本与数据
2.7V~3.6V
低功耗模式电流低至 1uA

2. 元件特性

flash 芯片 GD25LQ128C 是通过 SPI 串行闪存的芯片，具有 128M-bit（16 兆字节 MByte）空间，能够储存声音、文本和数据等；设备运行电源为 2.7V~3.6V，低功耗模式电流低至 1uA。

3. 读写擦除规则

操作规则
写数据每次都要按照页或者扇区或者簇为单位进行：一页 256 字节，一个扇区 4K 字节（16 页）；一次最多写一页（256 字节），超过一页数据长度则分多次完成
读数据可以从任何地址读出
擦除数据最小单位为一个扇区（4K），也可以直接擦除整个 flash 芯片
理解要点：Flash 的"写"受限制（按页、最多 256B），"读"很自由（任意地址）；写入前通常要先擦除（扇区/整片）。本实验写入 40KB 数据，w25qxx 驱动内部会自动分多次完成。

Flash 工作原理：为什么断电不丢

约 15 分钟

1. Flash 与 RAM 的区别

对比项FLASH（闪存）RAM（内存）
断电后数据可以保存不会保存（丢失）
典型用途程序、图片、参数长期存储运行时的变量、栈、堆
读写特性写前擦除、按页/扇区操作随机读写、速度快

FLASH 芯片是应用非常广泛的存储材料，与之对应的是 RAM 芯片，区别在于：FLASH 芯片断电后数据可以保存，而 RAM 芯片断电后数据不会保存。

2. 二进制与"物质填充"

计算机的储存方式是二进制，也就是 0 和 1，在二进制中 0 和 1 可以组成任何数。FLASH 芯片对 0 和 1 的处理方式是用物质填充：1 则填充，0 则不填充。这样就算断电之后，物质的性质也不会因为没有电而改变，所以再次读取数据的时候数据依然不变，这样就可以做到断电保存。

写入"1"
单元内填充物质
→
写入"0"
单元不填充
→
断电
物质性质不改变
→
再上电
读出的数据依然不变
记忆锚点："1 填充、0 不填充"——物质存的是"有没有"，电停了物质还在，所以数据不丢。

main.c 解析：初始化与读写流程

约 20 分钟

1. main.c 完整源码

#include <stdio.h>
#include "fpioa.h"
#include "sysctl.h"
#include "w25qxx.h"
#include "uarths.h"
#include "spi.h"

#define BUF_LENGTH (40 * 1024 + 5)   // 约40KB缓存
#define DATA_ADDRESS 0xB00000            // 写入起始地址

uint8_t write_buf[BUF_LENGTH];
uint8_t read_buf[BUF_LENGTH];

/**
* @brief flash初始化：设置SPI3/CS0，读ID校验
*/
int flash_init(void)
{
    uint8_t manuf_id, device_id;
    uint8_t spi_index = 3, spi_ss = 0;
    printf("flash init \n");

    w25qxx_init(spi_index, spi_ss, 60000000);
    /* 读取flash的ID */
    w25qxx_read_id(&manuf_id, &device_id);
    printf("manuf_id:0x%02x, device_id:0x%02x\n", manuf_id, device_id);
    if ((manuf_id != 0xEF && manuf_id != 0xC8) || (device_id != 0x17 && device_id != 0x16))
    {
        printf("w25qxx_read_id error\n");
        return 0;
    }
    else
    {
        return 1;
    }
}

/**
* @brief flash写入数据，打印写入耗时（us）
*/
void flash_write_data(uint8_t *data_buf, uint32_t length)
{
    uint64_t start = sysctl_get_time_us();
    w25qxx_write_data(DATA_ADDRESS, data_buf, length);
    uint64_t stop = sysctl_get_time_us();
    printf("write data finish:%ld us\n", (stop - start));
}

/**
* @brief flash读取数据，打印读取耗时（us）
*/
void flash_read_data(uint8_t *data_buf, uint32_t length)
{
    uint64_t start = sysctl_get_time_us();
    w25qxx_read_data(DATA_ADDRESS, data_buf, length);
    uint64_t stop = sysctl_get_time_us();
    printf("read data finish:%ld us\n", (stop - start));
}

/**
* @brief 主函数，程序的入口
*/
int main(void)
{
    /* 设置新PLL0频率 */
    sysctl_pll_set_freq(SYSCTL_PLL0, 800000000);
    uarths_init();

    /* 初始化flash */
    uint8_t res = 0;
    res = flash_init();
    if (res == 0) return 0;

    /* 给缓存写入的数据赋值（0~40964） */
    for (int i = 0; i < BUF_LENGTH; i++)
        write_buf[i] = (uint8_t)(i);

    /* 清空读取的缓存数据 */
    for (int i = 0; i < BUF_LENGTH; i++)
        read_buf[i] = 0;

    printf("flash start write data\n");

    /* flash写入数据 */
    flash_write_data(write_buf, BUF_LENGTH);

    /* flash读取数据 */
    flash_read_data(read_buf, BUF_LENGTH);

    /* 比较数据，如果有不同则打印错误信息 */
    for (int i = 0; i < BUF_LENGTH; i++)
    {
        if (read_buf[i] != write_buf[i])
        {
            printf("flash read error\n");
            return 0;
        }
    }
    printf("spi3 flash master test ok\n");
    while (1)
        ;
    return 0;
}

2. 主流程解读

系统准备：sysctl_pll_set_freq(SYSCTL_PLL0, 800000000) 设置 PLL0 时钟为 800MHz，uarths_init() 初始化串口。
初始化 Flash：flash_init()——SPI3/CS0、60MHz 初始化，读 ID 校验（失败打印 w25qxx_read_id error 并退出）。
准备缓存：write_buf 赋初值（第 i 字节 = i），read_buf 全部清零。
写入并计时：flash_write_data()——w25qxx_write_data 写入 0xB00000，打印耗时。
读回并计时：flash_read_data()——w25qxx_read_data 读回，打印耗时。
对比校验：逐字节对比，不同打印 "flash read error" 退出；全同打印 "spi3 flash master test ok"。
知识活页M8-T2-K2

关键代码详解

约 20 分钟

1. 读 ID 校验（认芯片）

w25qxx_read_id 返回两个字节：厂商 ID（0xEF=Winbond、0xC8=GD/GigaDevice）与设备 ID（0x17/0x16 等）。flash_init 里先初始化 SPI3/CS0（60MHz），再读 ID 与预期值对比——ID 对不上说明 SPI 通信、接线或芯片型号有问题，打印错误并返回 0。

2. 写入为什么慢：擦除 + 页编程

w25qxx.c 内部写数据前会先按扇区擦除（SECTOR_ERASE 0x20），再发送写使能（WRITE_ENABLE 0x06），然后按 PAGE_PROGRAM（0x02）每次最多一页 256 字节编程，期间查询状态寄存器忙标志（REG1_BUSY_MASK）等待完成。所以 40KB 数据要分成约 160 页写入，这也是写入耗时远大于读取的原因。

写使能
WRITE_ENABLE 0x06
→
扇区擦除
SECTOR_ERASE 0x20
→
页编程
PAGE_PROGRAM 0x02，≤256B/次
→
忙等待
查询状态寄存器
理解要点：Flash 写入=擦除+编程，慢且有限制；读取=直接按地址读，快且自由。这就是"写按页/扇区、读任意地址"规则在驱动层的体现。

3. 时间统计与数据校验

sysctl_get_time_us() 返回微秒级系统时间，在读写前后各取一次做差即可统计耗时。校验用逐字节对比：write_buf[i] 与 read_buf[i] 全等才打印 OK——这是嵌入式里最朴素也最可靠的数据一致性验证方法。

关键值取值说明
BUF_LENGTH40*1024+5 ≈ 40965B约 40KB，超一页需驱动分多次写
DATA_ADDRESS0xB00000写入起始地址（避开程序区）
PLL0800MHz系统主频，提高运算与传输能力
SPI 速率60MHzw25qxx_init 第三参数

4. 实验总结要点

实验总结：① GD25LQ128C 是一款存储空间为 16MB 的 FLASH 芯片，总共有 4096 个扇区，每个扇区有 16 页，每页是 256 字节；② FLASH 是能够断电保存数据的一种储存方式；③ FLASH 的擦除最小单位为扇区，也就是 4K。

拓展M8-X1

拓展任务：让 Flash 更实用

选做

拓展 1：写自己的数据

把 write_buf[i] = (uint8_t)(i) 改成写入自己的学号/姓名 ASCII 串（如 "2026-01 HNSW"），读回后串口打印字符串，验证读回一致。

拓展 2：改地址与长度

修改 DATA_ADDRESS（如 0x000000 附近观察是否覆盖程序区）与 BUF_LENGTH（如 10KB / 100KB），观察写入与读取耗时的变化，体会"页数越多写入越慢"。

拓展 3：掉电保存验证

烧录程序写入数据后，断电再上电；把读回功能单独保留，确认同一地址读出的数据仍在——直观感受"断电不丢"。

拓展 4：分区存储

把 Flash 按地址分成"配置区 / 数据区 / 日志区"三块，封装 save_config() / load_config() 函数，模拟保存用户设置（如阈值、颜色），思考：为什么每次写前要先擦除？

拓展 5（进阶）：定时记录传感器日志

结合模块五定时器：每秒把一次模拟数据（如递增计数器）写入 Flash 日志区，掉电后重新上电继续追加。思考：Flash 擦写次数有限（磨损），频繁写同一地址会怎样？工程上如何避免（磨损均衡）？

完成标准：至少完成拓展 1–3 中的两个，并在活页空白处记录每种改动的现象；拓展 4–5 可作为小组探究课题。
